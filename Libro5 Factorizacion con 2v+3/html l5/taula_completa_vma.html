2 · Salto Màxim i conjectura d'Andrica
NomEquació / definicióUtilitat
Conjectura
SaltoMàxim(n)
k = ⌊√n⌋ / 3 SaltoMàxim(n) = (2+4)·(k/2) = √n Interval mínim (dos primers) per n>3: I(n) = [n − ⌊√(n+3)⌋ − 3, n + 3] L(n) = ⌊√(n+3)⌋ + 7 K = ⌊⌊√n⌋ · 9/24⌋ m(n) = Σ_{i=2}^{K} √(n+3)/i! ≈ (e−2)·√n Criteri: L(n) − m(n) ≥ 2 → ≥2 primers en I(n)
Cota superior del buit entre primers; reforça Andrica; "dos primers en √n" verificat numèricament
Andrica
Límit asimptòtic
√n − √(n − √n) < 1 lím_{n→∞} [√n − √(n−√n)] → 0 < 1 → Si es compleix per un n₀, es compleix per tot n>n₀
Coherència de la conjectura d'Andrica per a tot n ≥ 1; provat via SaltoMàxim
3 · Estructura Sofí — isomorfisme Sophie Germain
NomEquació / definicióUtilitat
Isomorfisme Sofí
Conjunts L
L₁ = {n∈ℕ : n ≡ 5 mod 6} L₃ = {a∈L₁ : a = (6k−1)(6h+1)} L₄ = {a∈L₁ : 2a+1 = (6j−1)(6g+1)} L₂ = L₃ ∩ L₄ LSG = {p∈L₁ : p i 2p+1 primers} U₂ = L₁ ∖ (L₃ ∪ L₄) |L₁|+|L₂|−|L₃|−|L₄| = |LSG| U₂ ⊆ LSG LSG ∪ L₃ ∪ L₄ = L₁
Caracteritza exactament les primes de Sophie Germain via partició modular de L₁
Infinitud de U₂
Per tot q≥5 primer, per TXR: ∃ r mod 6q p ≡ r mod 6q → p ∈ L₄∖L₂ Per Dirichlet: ∞ tals p → |L₄∖L₂| = ∞ Anàlogament |L₃∖L₂| = ∞, |L₂| = ∞ ∴ |U₂| = ∞ → infinits prims Sophie Germain
Argument d'infinitud via TXR + Dirichlet; evita la hipòtesi directa sobre LSG
Férmines
Fermat modular
Fₙ = 2^(2ⁿ) + 1 F₀·F₁·…·Fₙ = Fₙ₊₁ − 2 Bₙ = 2·(F₀·F₁·…·Fₙ) ∃! rₙ : rₙ≡1 mod 2, rₙ≡2 mod Fₖ (k≤n) → ∀m≥n+1 : Fₘ ≡ rₙ mod Bₙ
Alineació modular dels Fermat; en base 2·∏Fₖ els Fermat prims queden a la primera fila
4 · Conjectura de Goldbach — asimetria i error quantitatiu
NomEquació / definicióUtilitat
Goldbach
Condició densitat
G(2n) = #{(p,q): p≤q, p+q=2n, ambdós primers} Condició necessària: f(x)·2 ≤ f(2x) G_teo(2n) ≈ 2n / (ln n)² E(2n) = (G(2n)−G_teo(2n)) / G_teo(2n) · 100%
Si la condició falla → conjectura falsa; E% decreix cap a 0, confirmat fins 5·10⁴
Error relatiu (forma 6k)
E_6k = ((n/6 − 2n/ln(2n)) · 100) / (2n/ln(2n)) Algoritme d'asimetria booleana: acumularFALLO += f(i) − (f(2x)−f(2x−i)) alarma si f(x)·2 ≤ f(2x)−acumularFALLO
Quantifica la desviació per tramos 6k; l'alarm mai salta → reforça la conjectura
Segmentació MRAUV
→ Goldbach
Δ = ⌊c·√n⌋, J = ⌊n/Δ⌋ A_j = [(j-1)Δ+2, jΔ+1] (tramo baix) B_j = [2n−jΔ−1, 2n−(j-1)Δ−2] (tramo alt) D⁻_j = D_pred((j-1)Δ, jΔ) via MRAUV D⁺_j = D_pred(2n−(j-1)Δ, 2n−jΔ) Acumular += (D⁺_j − D⁻_j) Criteri: D_1º + Acumular ≥ D_2º
Garanteix ≥1 parell Goldbach via densitats MRAUV per tramos simètrics; creix amb n
5 · MDC — Mètode Diofàntic Cinemàtic (nucli)
NomEquació / definicióUtilitat
MDC core
Funció d'ona
D(m) = 2·(2m+3) (candidat divisor) d(m) = frac(N / D(m)) (part decimal) Aritmètica entera exacta: R = N mod D ← numerador D ← denominador Condició de tall exacta: R == D // 2 → D | N (factor trobat)
Detecta divisors sense float; base del motor cinemàtic; precisió infinita per BigInt
Cinemàtica de la pinça
4 mesures per direcció → buffer circular V = ΔR/Δm (velocitat, Δ¹ dels restos) A = ΔV/Δm (acceleració, Δ²) J = ΔA/Δm (jerk, Δ³) Invariant parabòlic: A ≈ const → dent estable Desfase: mesura en 2 direccions simultànies
Determina la curvatura local de la "dent de serra"; prediu posició del mínim sense iterar
Salt Mestre (One-Shot)
m_next = m − V/A Verificació O(1): div = 2·(2·m_next+3) si N mod div == 0 → factor! Límit iteració: max_iter = 2·⌊log₂(N)⌋ Complexitat reclamada: O(log N)
Salta directament al vèrtex de la paràbola local; "balística matemàtica" determinista
6 · MDC — Radar, Rueda i Densitat de Supervivència
NomEquació / definicióUtilitat
Acumulador harmònic
(radar macroscòpic)
acumulo += acumulo · (1/i) (i = índex segment) Cerca des de: talla/2 = ⌊√N⌋ // 2 Llindar ressonància: acumulo ≤ umbral_R Si segment NO ressona → salt massiu al següent Si segment ressona → activar pinça cinemàtica
Filtre de primer nivell: descarta segments sencers en O(1); evita "pinces en terra estèril"
Rueda primorial (MDC-U)
p# = 2·3·5·7·…·pₖ (primorial fins pₖ) Illes vàlides per cicle: φ(p#) = (p₁−1)·(p₂−1)·…·(pₖ−1) Densitat activa: φ(p#) / p# Ex. p≤5: φ(30)=8, densitat = 8/30 ≈ 26.6% Ex. p≤7: φ(210)=48 posicions / cicle de 210
Elimina ≥73% de l'espai pre-MDC; la rueda de saltos és l'array de 48 (o φ(p#)) entrades
Funció de purgat
m(p) — recurrència
m(p) = m(p−1) + m(p−1) · (1/p) = m(p−1) · (1 + 1/p) [versió additive] Forma multiplicativa equivalent: ρ_nova = ρ_ant · (1 − 1/p) Densitat de supervivència: (1 − m(p)) · talla = isles vàlides en talla p# = m(p−1) / (m(p) − m(p−1)) [despejament]
Mesura exactament quant espai és matemàticament estèril; connecta ρ amb la funció de Euler ϕ
Radar topològic discret
(MDC-U fusió)
// Operar sobre ÍNDEXS de l'array d'illes, no sobre m isles = GENERAR_RUEDA(N, prims=[2,3,5]) ind_esq = 0; ind_dre = len(isles)−1 while ind_esq < ind_dre: ind_cen = (ind_esq+ind_dre)//2 sonda = PINÇA(N, isles[ind_cen]) si sonda.velocitat > 0: ind_dre = ind_cen sino: ind_esq = ind_cen si (ind_dre−ind_esq) < LLINDAR: candidat = isles[ind_esq] − V/A si N mod D(candidat)==0: return D(candidat)
Fusió rueda+pinça: busca binària sobre illes (O(log·φ(p#)·N)); sonda mai en terra estèril
7 · MRAUV — estimació cinemàtica de π(n)
NomEquació / definicióUtilitat
MRAUV
Model per trams
π(x) ≈ x · D(x) D_pred en [n, n+Δn]: D_pred ≈ D₀ + V₀·Δn + ½·a₀·(Δn)² (+ jerk opcional) Estimació: π(n+Δn) ≈ π(n) + D_pred·Δn Recalibrar cada ~2·√n per controlar error Coste: O(M) segments [M = N/Δn]
Estimació local de π amb control d'error explícit; alternativa a ln(x) amb precisió ajustable
8 · Criva (model de densitat modular iteratiu)
NomEquació / definicióUtilitat
Criva
Densitat modular
Dₙ = (a·p + b) / (b·p) ≡ a/b + 1/p Iteració: a = a·p + b; b = b·p Correcció cap a objectiu T = π(x)/x: Dₙ₊₁ = Dₙ + s·(T − Dₙ) = (1−s)·Dₙ + s·T Error: eₙ = e₀ · (1−s)ⁿ Iters. necessàries: n ≥ log_{1/(1-s)}(e₀/ε) Cas s=½: n ≥ log₂(e₀/ε) [~8 iters per 0.01%]
Superació de Legendre en precisió local; convergència controlada amb el paràmetre s; programable en C/Python
Model fractal per capes
(π̃ densitat)
D(x) = Σₙ₌₀ᵏ [ D₀ / 2ⁿ · wₙ(x) ] Capes: D₀≈0.445 (x<10³), D₁≈0.2233 (10³≤x<10⁵), D₂≈0.1302 (x≥10⁵) Transició suau: wₙ(x) = 1/(1+exp(−(x−xₙ)/s)) π(x) ≈ x · D(x) vs. clàssic π(x) ~ x/ln(x) Dₙ ≈ D₀·(1/2)ⁿ → error es redueix a la meitat/pas
Arquitectura escalable; reemplaza ln(x) per suma de densitats modulars; intuïtiva i ràpida
Heurística e−2
(model "dos primers")
π(n) ≈ n / (ln n − 2) Origen: assegurar ≥2 primers en √n sense comptar → el "−2" compensa la sobreestimació Convergència modular: C(x) = Σ_{p≤P} (a·p+b)/(b·p) π(x) ≈ C(x) · x [0 < C(x) < 1]
Ajust heurístic millor que Gauss per rangs baixos; base per la connexió amb la densitat de Criva
9 · Criba desmemoriada i criba híbrida
NomEquació / definicióUtilitat
Criba desmemoriada
Entrades: A=(010001), B=(011101), P=5, Pb=6 mentre P < límit: C = P veces A C[P]=0; C[Pb·P−P]=0 C = P veces C; C[P]=1 B = P²·veces B B = B AND C [des de P fins Pb·P²] mentre B[P+2]==0 && P
Ideal per memòria distribuïda; allibera el primer aviat; substitueix divisió per AND booleà
Criba híbrida
(ascendent+descendent)
1. Criba ascendent fins L/2 → llista de primers 2. Calcular restos: r = (L²−p²) mod p per cada p 3. Criba descendent des de L usant restos: j = L − r; j −= 2p; j −= 4p; ... 4. Combinar: B_tot = B_asc AND B_desc Salts: +2p / +4p en les dues direccions
Redueix remarcades (errors de doble marcatge) concentrades al final; millora Θ de l'ascendent sola

n=p₀; m=n+1; ny=n−1 t=ny²; tt=n²; nt=m² Per cada pas: t*=ny; tt*=n; nt*=m ny++; n++; m++ Booleanos: t1=t%ny; t2=t%n; t3=t%m; ... pas1 = (t3>0 AND nt2==0) OR ant_p1 OR ant2_p1 pas2 = pas1 AND t2>0 AND tt2>0 AND t3==0 OR ant_p2 pas3 = ant_p2 AND t1>0 AND (nt1+nt2)==0 si pas3 → ny és el pròxim primer
