# encriptacionGeometrica

**Encriptación por convergencia geométrica (VMA):** pares de bits, escalas de Thales, perímetros de polígonos, motor **K3** (base 33, rel 1) y demos Python/C.

Uso civil / educativo. Parte del **1** del monorepo 33×1.

## Qué contiene esta carpeta

| Pieza | Contenido |
|-------|-----------|
| `k3_core.c` | Núcleo C del motor K3 |
| `k3_launcher.py` | Lanzador / orquestación Python |
| `_demo_convergencia.py` | Demo de convergencia |
| `gemini-code-*.py` / `.c` / `.sh` | Iteraciones y experimentos (Gemini) |
| `deepseek_*.py` / `.c` / `.md` / `.txt` | Iteraciones y notas (DeepSeek) |
| `encriptacion.txt` | Notas de teoría / protocolo |
