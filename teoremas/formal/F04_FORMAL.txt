--------------------------------------------------------------------------------
1. DEFINICIONES
--------------------------------------------------------------------------------
  L₁ := { a ∈ ℕ : a ≡ 5 (mod 6) }
  L₃ := { a ∈ L₁ : ∃k,h : a = (6k−1)(6h+1) }     (compuestos)
  L₄ := { a ∈ L₁ : ∃j,g : 2a+1 = (6j−1)(6g+1) }  (2a+1 compuesto)
  L₂ := L₃ ∩ L₄

--------------------------------------------------------------------------------
2. TEOREMA
--------------------------------------------------------------------------------
  |L₄ \ L₂| = ∞.

--------------------------------------------------------------------------------
3. DEMOSTRACIÓN
--------------------------------------------------------------------------------
  Sea q ≥ 5 primo.
  (i)   2a+1 ≡ 0 (mod q) ⟺ a ≡ (q−1)/2 (mod q)  [q impar, 2 invertible mod q]
  (ii)  Sistema: a ≡ 5 (mod 6) ∧ a ≡ (q−1)/2 (mod q).
        Por TCR: ∃! r (mod 6q).
  (iii) gcd(r,6q)=1: r≡5(mod 6) evita 2,3; r≢0(mod q).
  (iv)  Dirichlet: infinitos primos p ≡ r (mod 6q).
  (v)   Cada tal p: p∈L₁; 2p+1≡0(mod q), q≥5 ⇒ 2p+1 compuesto ⇒ p∈L₄;
        p primo ⇒ p∉L₃ ⇒ p ∈ L₄ \ L₂.
  ∎

--------------------------------------------------------------------------------
4. COROLARIOS
--------------------------------------------------------------------------------
  C1. |L₄| = ∞.
  C2. q=5: p ≡ 17 (mod 30) ⇒ 2p+1 múltiplo de 5.
