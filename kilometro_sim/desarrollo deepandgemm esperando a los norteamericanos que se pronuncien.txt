Puedes copiar y ejecutar el siguiente script en Python. Modela un ciclo completo del módulo Kilómetro (bajada regenerativa controlada, patada impulsiva y avance lineal con rozamiento simulado) para calcular de forma precisa el balance de energía en julios:

Python
import numpy as np

# --- PARÁMETROS DEL SISTEMA (MÓDULO KILÓMETRO) ---
m = 50.0            # Masa móvil (kg)
g = 9.81            # Aceleración de la gravedad (m/s^2)
r = 1.0             # Radio/brazo de palanca (m)
eta_gen = 0.92      # Eficiencia del generador/variador
eta_mot = 0.90      # Eficiencia del motor en la patada

# Configuración del Ciclo
dt = 0.001          # Paso de integración (segundos)
t_max = 5.0         # Tiempo máximo de simulación (s)

# FASES DEL CICLO
# Fase A: Bajada lenta angular (0 a 180 deg) con regeneración (omega controlada baja)
omega_target = 0.5  # rad/s (bajada lenta controlada)

# Fase B: Patada impulsiva (durante el 1/4 desfavorable de 90 deg)
F_patada = 1200.0   # Fuerza de la patada (N)
t_patada_dur = 0.2  # Duración del impulso (s)

# Fase C: Avance lineal en recorrido gravitatorio con rozamiento simulado
F_avance_gen = 300.0 # Fuerza de frenado regenerativo en avance (N)
dist_avance = 2.0   # Longitud de la guía de avance (m)

# --- VARIABLES DE ESTADO ---
theta = 0.0         # Ángulo (rad)
omega = 0.1         # Velocidad angular (rad/s)
x_avance = 0.0      # Posición en avance (m)
v_avance = 0.0      # Velocidad de avance (m/s)

# Registros de Energía (Julios)
E_gen_bajada = 0.0
E_cons_patada = 0.0
E_gen_avance = 0.0

time = 0.0
fase = "A_BAJADA"

print("--- INICIANDO SIMULACIÓN NUMÉRICA DEL PROYECTO KILÓMETRO ---")

while time < t_max:
    # 1. FASE A: Bajada regenerativa angular lenta (0 a PI rad)
    if fase == "A_BAJADA":
        # Par gravitatorio actuante
        tau_grav = m * g * r * np.sin(theta)
        
        # Par regenerativo necesario para mantener omega_target
        tau_gen = max(0.0, tau_grav - 0.1 * (omega - omega_target))
        
        # Potencia extraída
        P_gen = tau_gen * omega * eta_gen
        E_gen_bajada += P_gen * dt
        
        # Aceleración angular
        alpha = (tau_grav - tau_gen) / (m * r**2)
        omega += alpha * dt
        theta += omega * dt
        
        if theta >= np.pi:
            fase = "B_PATADA"
            t_patada_start = time

    # 2. FASE B: Inyección impulsiva ("Patada")
    elif fase == "B_PATADA":
        if (time - t_patada_start) <= t_patada_dur:
            # Consumo motor
            P_mot = (F_patada * v_avance) / eta_mot if v_avance > 0 else (F_patada * 1.0) / eta_mot
            E_cons_patada += P_mot * dt
            
            # Aceleración del impulso
            a_patada = (F_patada - m * g * 0.5) / m # Asumiendo componente desfavorable
            v_avance += a_patada * dt
            x_avance += v_avance * dt
        else:
            fase = "C_AVANCE_REGENERATIVO"

    # 3. FASE C: Avance lineal con rozamiento simulado (Generación)
    elif fase == "C_AVANCE_REGENERATIVO":
        F_grav_fav = m * g * 0.8 # Componente a favor en el recorrido útil
        
        if F_grav_fav > F_avance_gen:
            a_avance = (F_grav_fav - F_avance_gen) / m
        else:
            a_avance = 0.0
            
        v_avance += a_avance * dt
        x_avance += v_avance * dt
        
        P_gen_lin = F_avance_gen * v_avance * eta_gen
        E_gen_avance += P_gen_lin * dt
        
        if x_avance >= dist_avance:
            break

    time += dt

# --- RESULTADOS DEL BALANCE ENERGÉTICO ---
E_total_generada = E_gen_bajada + E_gen_avance
E_total_consumida = E_cons_patada
E_neto = E_total_generada - E_total_consumida

print(f"\nResultados del Ciclo Completo:")
print(f"  - Energía Generada en Bajada Angular:  {E_gen_bajada:.2f} J")
print(f"  - Energía Consumida en Patada:         {E_cons_patada:.2f} J")
print(f"  - Energía Generada en Avance Lineal:   {E_gen_avance:.2f} J")
print(f"  --------------------------------------------------")
print(f"  - ENERGÍA TOTAL GENERADA:              {E_total_generada:.2f} J")
print(f"  - BALANCE NETO POR CICLO:              {E_neto:.2f} J")

if E_neto > 0:
    print("\n [¡EXITO!] El ciclo produce un EXCEDENTE neto de energía.")
else:
    print("\n [AJUSTE REQUERIDO] La patada consume más de lo que compensa el ciclo. Ajustar F_patada o t_patada.")

5) Sobre “doble kilómetro por perneo”



Encaja como acoplamiento inercial / buffer de potencia (un módulo quieto y “perneado”, al despernear reparte de golpe lo almacenado): útil como supercondensador mecánico para picos y fase, no como fuente de julios gratis.



La gravedad es un campo conservativo: en ciclo cerrado el trabajo neto de la gravedad es ~0. Lo que puedes hacer bien es:



• bajar lento (cosechar) / subir rápido (patada) → gestión de tiempo de ciclo

• rozamiento adaptativo → mejor η de conversión, no η > 1

• doble en perpendicular + perneo → suavizar picos y acoplar fases

Desglose de desperdicio: Tiempo vs. Operación

Pérdida pasiva (en función del tiempo): 0 %/mes. Si mantienes la masa suspendida o trancada durante seis meses, recuperarás exactamente la misma energía potencial cuando decidas liberar el freno.

Pérdida dinámica (eficiencia ida y vuelta / RTE): 20% – 30% por ciclo. El desperdicio no ocurre por dejar guardada la energía, sino al moverla: fricción de guías/sellos, pérdidas mecánicas en la transmisión y rendimiento de la máquina eléctrica (motor/generador).
