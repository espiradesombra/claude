vma-run/  ★ NUEVO — ejecutable unificado
  vma_run.py + lib/ (mdc, criva, cribas, k3_phase, hypotenuse)
  Un comando = toda la demostración VMA lista para enseñar.

gemelos/  (15 archivos)
  Gemelos digitales Quijote + ZypyZape (v3 → v10).
  Física NREL 5MW, Kuramoto, buffer hidráulico, control de pitch.
  Valor: due diligence técnica, simulación reproducible, base de paper.

  Empezar por:
    gemelo_v6_fisic.py      — física real r_q, buffer hidráulico
    gemelo_v942.py          — versión más refinada (K_q, válvulas, estados)
    zypyzape_twin_v4_8_quijote.py — gemelo de red completo (swing equation)

zypyzape-contexto/  (18 archivos)
  Documentación y contexto que explica los números.
    01_CONTEXT_ZYPYZAPE.txt — parámetros exactos v4.8, resultados validados
    02_MATH_QUIJOTE_3vs7.txt — Factor_N = 2·sin(π/N), ball vs estático
    resumen de dinero...txt — evaluación honesta mercado / continentes
    dossier-elewit/         — material presentación REE/Elewit (si existe)

hurto-gravitatorio/  (7 archivos)
  Resultados positivos de hurto gravitatorio (simulación NREL 5MW, T=90s).

  DATOS CLAVE (quijote_results.csv):
    3 pales PAPER:  P_net = +9.0 kW,  η_hurto = 3.0×, ΔP_grid = +4.16%
    7 pales PAPER:  P_net = +31.1 kW, η_hurto = 3.7×, ΔP_grid = +4.31%
    Modo CONTROL (centrífuga práctica): aún negativo — pendiente cerrar brecha.

  Ejecutar:
    python gemell_quijote_paper_rules.py   → regenera CSV + tabla LaTeX

vma-k3/  (~30 archivos, solo código — sin zips/vídeos de _entrada)
  Motor industrial Theorem K3 — Python + C.
  TRL 3-4. NO criptográfico: auditoría memoria, telemetría, fingerprinting.

  Instalar y usar:
    cd vma-k3
    pip install -e .
    vma-k3 --modo usual "LECTURA_DE_SENSORES_DATA"
    python examples/run_modos.py

antipc/  (69 archivos)
  AntiPC — Adaptive Network Through Parallel Computing.
  TRL 4-5. Runtime con plugins K3, MDC, UDP fabric, demos industriales.
  Especificación fundacional: gptcomputing\ (conversación v0.0.01 → v0.1.0).

  Empezar:
    INICIO.bat
    o: scripts\01_instalar.bat → scripts\02_benchmark.bat
    o: RUN.bat antipc  (desde raíz)

    cd gemelos

    python zypyzape_twin_v4_8_quijote.py

  Paso 5 — K3 industrial (30 seg)
    cd vma-k3
    pip install -e .
    vma-k3 --modo propio-b --bits 32 --registros 4 datos_ejemplo.txt

  Paso 6 — Aleatorovix (30 seg)
    cd aleatorovix
    python criba_desmemoriada.py
    python mdc_v6_aleatorovix.py

  Paso 7 — AntiPC (cuando quieras red)
    gptcomputing\CONCEPTO.txt     (opcional, 5 min — contexto del runtime)
    cd antipc

    o: RUN.bat antipc
