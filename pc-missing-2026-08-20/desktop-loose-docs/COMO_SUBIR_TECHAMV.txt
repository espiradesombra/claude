PASOS EN NOMINALIA / FTP (techamv.com)
================================================================================

A) Entra en el panel de Nominalia (o el hosting que uses para techamv.com)
   → FTP / Archivos / File Manager / Gestor de archivos.

B) Abre la carpeta pública del dominio:
   - suele llamarse: public_html  o  www  o  httpdocs  o  techamv.com

C) HAZ COPIA DE SEGURIDAD del index.html actual (renómbralo a index-backup.html).

D) Sube desde techamv-aleatorovix-DEPLOY:
   - index.html          → raíz del sitio
   - carpeta aleatorovix → con aleatorovix.js dentro
     (debe quedar:  public_html/aleatorovix/aleatorovix.js)

E) Abre https://techamv.com  y pulsa el botón de suerte.
   F12 → Consola: no debe decir "failed to load aleatorovix.js".

F) Si usas FileZilla / WinSCP:
   - Host: el que te dio Nominalia (ftp.techamv.com o similar)
   - Usuario / contraseña del FTP
   - Arrastra la carpeta DEPLOY al public_html
