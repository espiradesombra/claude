\# METHOD: Phase‑Boolean Feedback with K‑Path Summation  

\## Technical exploration of K‑shifted Toffoli sums for phase‑sensitive logic  



\*\*Versió:\*\* 1.0  

\*\*Autor:\*\* 1477 / 33x1  



---



\## 1. State encoding (4 bits)



A two‑qubit system with Boolean phase encoding:



\- `v1` : value of qubit 1 (0 or 1)  

\- `f1` : phase of qubit 1 (0 → +1, 1 → –1)  

\- `v2` : value of qubit 2  

\- `f2` : phase of qubit 2  



State: `S = (v1, f1, v2, f2)` ∈ {0,1}⁴.



---



\## 2. Permutation (phase shift)



Only the value bits `(v1, v2)` are permuted following a cyclic Gray order:



| (v1, v2) | shift(v1, v2) |

|----------|----------------|

| 00       | 11             |

| 01       | 10             |

| 11       | 00             |

| 10       | 01             |



The phase bits `(f1, f2)` remain in the same position (they are not permuted, only the values move).



Formally:  

`shift(v1, f1, v2, f2) = (v1', v2', f1, f2)`  

where `(v1', v2')` is given by the table above.



---



\## 3. Quantum Boolean gate (Toffoli)



Toffoli gate that preserves the phase of the first qubit and sets the second qubit’s phase to 0:



`Toffoli(S) = (v1, f1, v1∧v2, 0)`



The same structure can be used for other gates (CNOT, CZ, etc.) by changing the Boolean operation on values.



---



\## 4. K‑path sum



For a given integer `K ≥ 1`, define the sum (XOR) of the Toffoli outputs applied to `K` successive shifts of `S`:



`T\_K(S) = Toffoli(S)  ⊕  Toffoli(shift(S))  ⊕  Toffoli(shift²(S))  ⊕ …  ⊕  Toffoli(shift^{K-1}(S))`



where `⊕` is bitwise XOR.



---



\## 5. Feedback rule



Two possible feedback rules:



\- \*\*OR feedback:\*\*  

&nbsp; `S\_next = S  OR  T\_K(S)`   (bitwise OR)

\- \*\*XOR feedback:\*\*  

&nbsp; `S\_next = S  XOR  T\_K(S)`   (bitwise XOR)



The process is iterated for a fixed number of cycles (e.g., 6).



---



\## 6. Invariants



For \*\*XOR feedback\*\*, the following holds:



\- Because every `Toffoli` output has `f2 = 0`, the XOR of any number of them also has `f2 = 0`.  

\- Then `f2\_next = f2 ⊕ 0 = f2`.  

\- \*\*Invariant:\*\* `f2` never changes. The state space splits into two disconnected subsets: `f2=0` and `f2=1`.



For \*\*OR feedback\*\*, no simple bitwise invariant exists (but global attractors may appear).



---



\## 7. Initial conditions for phase sensitivity test



We compare two trajectories starting from states that are identical except for `f1`:



\- `S\_A = (0, 0, 1, 0)`   (f1 = 0)

\- `S\_B = (0, 1, 1, 0)`   (f1 = 1)



Both have `f2 = 0` (same subset).



We compute the Hamming distance between the two trajectories at each cycle:



`D(t) = Hamming( S\_A(t), S\_B(t) )`   where `S\_A(0) = S\_A`, `S\_B(0) = S\_B`.



---



\## 8. Exploration plan (K and feedback)



We systematically vary:



\- \*\*K = 1, 2, 3, 4, 5, 6, 7, 8\*\*  (since shift⁴ = identity, K > 4 may repeat patterns with different parity)

\- \*\*Feedback = OR, XOR\*\*



For each combination, compute:



1\. The full transition function for all 16 states.

2\. The cycles (period, number of cycles, fixed points).

3\. The distance evolution `D(t)` for the two initial states S\_A, S\_B.

4\. Whether the difference in `f1` ever propagates to the value bits `v1` or `v2` in a persistent way (i.e., after some cycle, all future states have `v1` or `v2` different between the two trajectories).



---



\## 9. Expected outcomes (from preliminary analysis)



\- \*\*K=3, XOR feedback:\*\*  

&nbsp; - `f2` invariant (two disjoint 8‑state subspaces).  

&nbsp; - Within `f2=0`, states evolve in cycles of length 4 (two cycles of 4 states each).  

&nbsp; - Distance between S\_A and S\_B: initial 1, then 3, then oscillates (never returns to 0).  

&nbsp; - Phase difference `f1` does affect value bits `v1, v2` in alternating cycles.



\- \*\*K=1, XOR feedback:\*\*  

&nbsp; - Distance stays 1 (no propagation to values).  

\- \*\*K=2, XOR feedback:\*\*  

&nbsp; - Distance always 1 or 0? (to be verified).  

\- \*\*K=3, OR feedback:\*\*  

&nbsp; - Converges to fixed point with distance 0 (phase difference erased).  

\- \*\*K=4, any feedback:\*\*  

&nbsp; - Returns to K=0 behaviour (shift⁴ = identity, sum of 4 identical Toffoli outputs cancels in pairs if XOR).



---



\## 10. How to use this document



1\. Implement the functions `shift`, `Toffoli`, `T\_K`, and the feedback rule in Python (or any language).

2\. Run the exploration for all K = 1..8 and both feedback types.

3\. Record transitions, cycles, and distance sequences.

4\. Identify the combination(s) where `f1` permanently alters `v1` or `v2`.

5\. Use that combination as a \*\*phase‑to‑value amplifier\*\* for detecting hidden phase differences with classical logic.
