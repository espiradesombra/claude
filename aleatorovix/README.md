# aleatorovix — organismo de entropía

Organismo **Aleatorovix**: entropía, máscara Lila, criba desmemoriada, MDC, demos y benchmarks. Base del motor web sin `Math.random`.

**Monorepo:** [espiradesombra/claude](https://github.com/espiradesombra/claude) · ruta: `aleatorovix/`

## Qué contiene esta carpeta

| Pieza | Contenido |
|-------|-----------|
| `aleatorovix.py, nucleo/` | Núcleo Python (entropía, Lila, criba, MDC, acciones) |
| `demos/, benchmarks/` | Demos y benches |
| `organismo_lila_v99.c` | Versión C del organismo |
| `ALEATOROVIX.txt, CONCEPTO.txt, LEEME.txt` | Corpus y concepto |
| `RUN_ALEATOROVIX.bat` | Arranque rápido |
