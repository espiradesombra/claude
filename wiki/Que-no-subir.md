# Qué no subir al monorepo

| No | Por qué |
|----|---------|
| Contraseñas FTP, tokens, `.env`, `.pem` | Seguridad |
| Chats con teléfonos / NIF / datos personales | Privacidad |
| Vídeos enormes `.mp4`, dumps de móvil | Peso y ruido |
| Cracks, software pirata | Legal / basura |
| `__pycache__`, `.pyc`, builds locales | Regenerables |
| Zips gigantes duplicados del monorepo | Ya está el árbol |

## Sí subir (con commit por carpeta)

- Código, demos, docs, READMEs  
- Packs mínimos de deploy (HTML/JS/iconos)  
- Fichas de teoremas y papers del autor  
- Mejoras de wiki / MAPA / FOLDERS
