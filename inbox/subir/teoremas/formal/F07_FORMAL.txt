1. DEFINICIONES
--------------------------------------------------------------------------------
  Dado primo p₀, definir estado:
    n := p₀, m := n+1, ny := n−1
    Acumuladores: t := ny², tt := n², nt := m²
    Restos R := { t, tt, nt } mod { ny, n, m }

--------------------------------------------------------------------------------
2. PROCEDIMIENTO SIGUIENTE_PRIMO(p₀)
--------------------------------------------------------------------------------
  Repetir:
    Calcular 9 restos por iteración.
    Evaluar 3 pasos lógicos (tabla Karnaugh).
    SI patrón = primo ⇒ retornar candidato.
    SI patrón = compuesto ⇒ incrementar y continuar.

--------------------------------------------------------------------------------
3. CONJETURA DE CORRECCIÓN (no demostrada)
--------------------------------------------------------------------------------
  ∃ función next: ℙ → ℙ tal que next(p) = min{ q ∈ ℙ : q > p }
  y el procedimiento VMA termina en next(p₀) para todo p₀.
