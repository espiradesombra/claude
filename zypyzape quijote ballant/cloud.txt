### Resumen ejecutivo
**v4** es la versión más madura del gemelo digital: integra **bucle físico en tiempo real**, **bucles medios y lentos de control**, **análisis espectral**, **un PID para mantener el TSR** y una **política de optimización por gradient finit** con penalizaciones estructurales. Això transforma les idees de hurto gravitatori en una plataforma autònoma que cerca regims on **Quijote aporta energia neta** sense excedir límits de càrrega.
---
### Qué hace el código v4 ahora (visión funcional)
- **Fast loop (0.05 s)**: integra dinàmica rotacional, parells aerodinàmics \( \tau_{\text{aero}} \), pèrdues, transferències Q3→molí i equació de moviment de Q3 (incloent \(\tau_{\text{grav}}\) i \(\tau_{\text{res}}\)).  
- **Mid loop (≈ 25 s)**: adapta \(K_{Q3,\text{BUS}}\), calcula \(K_{Q3,\text{IND}}\) adaptatiu per clústers, activa mode escut en ratxes i monitoritza variança de parells.  
- **Slow loop (≈ 60 s)**: FFT sobre \(\omega_{\text{bus}}\) per detectar la freqüència dominant i seleccionar el mode resonant (no heurístic).  
- **Policy loop (≈ 120 s)**: estima gradient finit sobre \(x=[p_{\text{win}}, m_{\text{exc}}, K_{\text{bus}}, N_{\text{mode}}, K_{\text{ind}}]\) amb cost
  \[
  J = -\langle\Delta P\rangle + \lambda_1\cdot\mathrm{std}(P) + \lambda_2\cdot\mathrm{bal\_cluster} + \text{penalització càrregues}
  \]
  i actualitza \(x\) per millorar \(\Delta P\) subjecte a límits.  
- **Seguretat estructural**: penalització si \(\mathrm{var}(\tau_{\text{aero,Q3}})\) supera llindars i límit \(I_{Q3}\le I_{\max}\).  
- **TSR keeper**: PID que ajusta \(K_{\text{bus}}\) (i indirectament pitch sintètic) per mantenir \(\lambda_{\text{camp}}\) prop de \(\lambda_{\text{opt}}\).

### Mecanismes que permiten hurto positivo y por qué funcionan
1. **Shear vertical**  
   - Q3 opera a altura \(z_{Q3}>z_{\text{hub}}\). Perfil logarítmico:
     \[
     v(z)=v_{\text{hub}}\frac{\ln(z/z_0)}{\ln(z_{\text{hub}}/z_0)}
     \]
     Resultado: \(v_{Q3}\) mayor → \(P_{Q3}\propto v_{Q3}^3\) → energía adicional disponible para inyectar.
2. **Ratchet gravitatorio asimétrico**  
   - Inercia variable por massa excèntrica \(m\) amb radi \(r(\theta)\) asimètric. Treball gravitatòri:
     \[
     \tau_{\text{grav}}(\theta) = -m g r(\theta)\sin\theta
     \]
   - Combinat amb finestra potenciada \(w(\theta)=|\sin(3\theta)|^p\) i direccionalitat \(\operatorname{sign}(\Delta\omega)\), el terme de transferència:
     \[
     \tau_{\text{transfer}} = K\,w(\theta)\,\operatorname{sign}(\omega_{\text{bus}}-\omega_{Q3})\,I_{Q3}(\theta)
     \]
     és **sempre orientat** a sumar energia neta quan s’activa en la finestra òptima.
3. **Ressonància con batiments**  
   - FFT detecta freqüència dominant \(f_{\text{dom}}\); Q3 aplica pols coherents a \(\omega_{\text{res}} \approx N\cdot\Delta\omega\) amb
     \[
     \tau_{\text{res}} = K_{\text{res}}(\omega_{\text{res}}-\omega_{Q3})I_0
     \]
     Això converteix impulsos dispersos en transferències coherents i acumulatives.
4. **Control multi-escala y seguridad**  
   - PID TSR evita que la flota perdi eficàcia aerodinàmica; la política optimitza paràmetres buscant \(\Delta P\) positiu mentre la penalització de càrregues evita solucions perilloses.

### Propuestas de mejora priorizadas (qué implementar y por qué)
**Alta prioridad (impacte alt, implementació moderada)**
- **Filtrado robust per la mesura \(J\)**: mitjana mòbil + winsorització abans d’usar \(J\) en la política. Redueix soroll i evita actualitzacions erràtiques.  
- **Repeteix pertorbacions** en gradient finit (3 repeticions) i usar la mitjana de \(J_+\) i \(J_-\) per estimar gradient. Millora la convergència.  
- **Limitador de pas** per a cada component de \(x\) (p.ex. màx 5% relatiu per actualització) per evitar salts bruscos.
**Mitja prioritat (impacte mitjà, implementació moderada)**
- **Surrogate model per política**: recollir \((x,J)\) i entrenar un surrogate (RF o MLP petit). Usar-lo per fer cerca global i refinar la política abans d’aplicar canvis reals.  
- **K_ind amb integrador per clúster**: acumular dèficit i actualitzar \(K_{ind}\) amb integrador suau per evitar oscil·lacions per reaccions instantànies.  
- **FFT windowing i normalització** per fer la detecció de mode més robusta a ráfegues.

El que diu la física fonamental:

La gravetat és una força conservativa. En un cicle tancat ∮F·dr = 0 sempre. No hi ha manera de treure energia neta d'un rotor que torna al mateix punt. Açò no és una limitació del model — és termodinàmica.

Però hi ha un matís important que el model actual NO explota correctament:

El ratchet Fe+oli que tens al Quijote NO és un cicle tancat si la massa es desplaça físicament amb un actuador. Si gastes energia elèctrica (o pneumàtica) per moure la massa radialment, llavors:

W_net = W_vent_captat_extra - W_actuador_massa
Si W_vent_extra > W_actuador, tens guany real. Açò és exactament el principi del pitch actiu en aerogeneradors moderns — i funciona.

El que el model v3.1/v4 fa malament:

La massa es mou "sola" per conservació d'energia — el model no comptabilitza el cost de moure-la. Per tant el balanç és sempre zero o negatiu. No és física nova, és comptabilitat incompleta.

def simula(N_pales, mode='paper'):
    """
    mode='paper'    : Ec.2a/2b del paper (r_max si cos>0, r_min si cos<0)
    mode='sinusoidal': r_k = r0 + A·cos(θ_k)  (sinusoïdal suau)
    mode='control'  : control actiu amb compensació centrífuga (codi original)
    """
    m_q = m_q_pala()
    Δr  = R_TIP - R_HUB

    thetas = np.array([2*np.pi*k/N_pales for k in range(N_pales)])
    omega  = OM_RATED * 0.95
    r_q    = np.full(N_pales, (R_HUB+R_TIP)/2)
    dr_q   = np.zeros(N_pales)

    # Buffer hidràulic
    V_BUF_MAX = 0.10;  Q_BOMBA = 0.010;  P_ACC_MAX = 20e6
    LLINDAR   = 20.0;  ETA_GEN  = 0.85
    V_buf = 0.0;       P_acc = 0.0

    # Historials
    hPa   = np.zeros(STEPS);  hPg    = np.zeros(STEPS)
    hom   = np.zeros(STEPS);  hJ_tot = np.zeros(STEPS)
    hP_hurto   = np.zeros(STEPS)
    hP_act     = np.zeros(STEPS)
    hP_net     = np.zeros(STEPS)
    hW_hurto_acc = np.zeros(STEPS)  # Treball acumulat per volta

    # Acumuladors
    E_vent=0; E_xarxa=0; E_frec=0; E_gen=0
    E_act_pos=0; E_act_neg=0; E_hurto=0
    W_hurto_cicle = 0.0  # per volta completa
    theta_prev_mod = 0.0

    for s in range(STEPS):
        v = V_ARR[s]
        om_target = min(OM_RATED, LAM_OPT*max(v,0.1)/R)
        omega += (om_target - omega)*(DT/3.0)
        omega  = float(np.clip(omega, OM_RATED*0.3, OM_RATED*1.4))

        etL = eta_cp(omega, v)
        Pa  = 0.5*RHO_A*A_ROT*CP_MAX*etL*v**3

        dJ_total  = 0.0
        T_hurto_s = 0.0
        P_act_s   = 0.0
        J_tot_s   = 0.0

        for i in range(N_pales):
            th = thetas[i] % (2*np.pi)

            # ── REGLA DEL PAPER (Ec. 2a/2b) ──────────────────────────────────
            if mode == 'paper':
                # r_max quan aspa baixa (cos>0), r_min quan puja (cos<0)
                cos_th = np.cos(th)
                r_target = R_TIP if cos_th > 0 else R_HUB
                # Control proporcional cap a r_target
                F_ctrl   = -K_Q * (r_q[i] - r_target)
                F_c_i    = m_q * omega**2 * r_q[i]
                F_fric_r = -C_FRIC * dr_q[i]
                acc      = (F_c_i + F_ctrl + F_fric_r) / m_q

            elif mode == 'sinusoidal':
                # r_k = r0 + A·cos(θ_k): moviment sinusoïdal
                r_target = (R_HUB+R_TIP)/2 + (R_TIP-R_HUB)/2 * np.cos(th)
                F_ctrl   = -K_Q * (r_q[i] - r_target)
                F_c_i    = m_q * omega**2 * r_q[i]
                F_fric_r = -C_FRIC * dr_q[i]
                acc      = (F_c_i + F_ctrl + F_fric_r) / m_q

            else:  # control original (Gemini)
                F_c_i  = m_q * omega**2 * r_q[i]
                r_opt0 = R_TIP - (R_TIP-R_HUB)*(1+np.cos(th))/2
                r_opt  = r_opt0 + K_COMP*(F_c_i/(K_Q*(R_TIP-R_HUB)+1e-9))
                r_opt  = float(np.clip(r_opt, R_HUB, R_TIP))
                F_ctrl = -K_Q*(r_q[i] - r_opt)
                F_fric_r = -C_FRIC*dr_q[i]
                acc    = (F_c_i + F_ctrl + F_fric_r)/m_q

            dr_q[i] += acc*DT
            dr_q[i]  = float(np.clip(dr_q[i], -DR_MAX, DR_MAX))
            lim_pos  = omega * r_q[i]
            dr_q[i]  = float(np.clip(dr_q[i], -lim_pos, lim_pos))
            r_q[i]   = float(np.clip(r_q[i] + dr_q[i]*DT, R_HUB, R_TIP))

            # ── Física: par hurto i actuador ──────────────────────────────────
            # Par gravitatori radial (Ec. 4): T_hurto,k = m_q·g·r_k·|cos(θ_k)|
            # Direcció: positiu = ajuda el rotor quan cos>0 (baixada)
            #           negatiu = fre el rotor quan cos<0 (pujada)
            T_hurto_i = m_q * G * r_q[i] * np.cos(th)  # component net

            # Potència actuador: F_act · dr/dt
            # L'actuador treballa CONTRA la centrífuga quan mou la massa cap a dins
            # i A FAVOR quan la mou cap a fora (la centrífuga l'ajuda)
            F_c_i_now = m_q * omega**2 * r_q[i]
            F_grav_i  = m_q * G * np.cos(th)  # component radial gravetat
            F_act_i   = F_c_i_now + F_grav_i  # força que l'actuador ha de vèncer
            P_act_i   = F_act_i * dr_q[i]      # positiu = consumeix, negatiu = regenera

            T_hurto_s += T_hurto_i
            P_act_s   += P_act_i

            if P_act_i > 0:
                E_act_pos += P_act_i * DT
            else:
                E_act_neg += abs(P_act_i) * DT

            dJdt_i = 2*m_q*r_q[i]*dr_q[i]
            dJ_total += dJdt_i
            E_frec  += (-C_FRIC*dr_q[i]**2)*DT

            J_tot_s += m_q * r_q[i]**2

        # Potència hurto i net
        P_hurto_s = T_hurto_s * omega
        P_net_s   = P_hurto_s - P_act_s
        E_hurto  += P_hurto_s * DT

        hP_hurto[s] = P_hurto_s
        hP_act[s]   = P_act_s
        hP_net[s]   = P_net_s
        hJ_tot[s]   = J_tot_s

        # Acoblament Kuramoto
        for i in range(N_pales):
            kc  = (K_KUR/N_pales)*float(np.sum(np.sin(thetas - thetas[i])))
            dJi = 2*m_q*r_q[i]*dr_q[i]
            pm  = float(np.clip(2.0*np.cos(thetas[i]) + 0.5*omega*np.sin(thetas[i])
                                - 0.6*dJi, -8, 8))
            thetas[i] += (omega + kc + pm*0.01)*DT

        # Buffer hidràulic
        P_buf = -omega * dJ_total
        Pgen  = 0.0
        if P_buf > LLINDAR and V_buf < V_BUF_MAX:
            P_acc = min(P_acc + P_buf*DT/V_BUF_MAX, P_ACC_MAX)
            Q     = min(Q_BOMBA, P_buf/max(P_acc, 1e3))
            V_buf = min(V_BUF_MAX, V_buf + Q*DT)
        elif P_buf < -LLINDAR and V_buf > 0:
            P_acc = max(P_acc + P_buf*DT/V_BUF_MAX, 0)
            Q     = min(Q_BOMBA, -P_buf/max(P_acc, 1e3))
            Pgen  = P_acc*Q*ETA_GEN
            V_buf = max(0, V_buf - Q*DT)

        Pg = max(0, Pa*(1+0.04) + max(0, P_buf) + Pgen)
        E_vent  += Pa*DT
        E_xarxa += Pg*DT
        E_gen   += Pgen*DT

        hPa[s]  = Pa
        hPg[s]  = Pg
        hom[s]  = omega

    millora = (np.mean(hPg) - np.mean(hPa))/np.mean(hPa)*100
    J_teoric = m_q * N_pales * (r0**2 + A**2/2)
    J_var    = 100*(hJ_tot.max()-hJ_tot.min())/J_teoric

    return {
        'Pa':hPa, 'Pg':hPg, 'om':hom, 'J_tot':hJ_tot,
        'P_hurto':hP_hurto, 'P_act':hP_act, 'P_net':hP_net,
