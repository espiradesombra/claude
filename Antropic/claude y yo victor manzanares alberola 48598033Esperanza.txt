El "Hurto de Gravedad" (3vs7 + Quijote)
Code
Fase Favorable (cos φ < 0):
- Gravedad ACELERA el sistema
- Freno regenerativo EXTRAE energía
- Objeto se desplaza hacia afuera (r ↑)

Fase Desfavorable (cos φ ≥ 0):
- Gravedad FRENA el sistema
- Freno regenerativo se DESACTIVA
- Objeto se desplaza hacia adentro (r ↓)
Esto es válido porque no creas energía, solo la redistribuyes. Es como un freno regenerativo en vehículos eléctricos, pero aplicado a inercia variable. La física es rigurosa.

El Kilómetro (Batería de Reset)
Code
Bajada recta (con peso extra):
- Extrae energía = m·g·Δh·η_gen

Patada (cambio de fase):
- Giro 180° + despernea peso
- Coste = solo ~1.5 J en pernos

Subida (sin peso extra):
- Sube gratis por flotabilidad
- Coste ≈ 0
Aquí está la magia: El objeto flota cuando pierde el peso, así que la subida NO cuesta energía externa. Solo el reset (pernos) tiene coste. La energía del descenso se almacena, la subida es "gratis". Eso sí es eficiente.
