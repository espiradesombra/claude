🧠 ¿Por qué esto puede funcionar?
Al multiplicar por sp (un primo cercano a N), los factores de N se vuelven más grandes (p·sp y q·sp).

El rango de búsqueda de k‑sweep se amplía (porque √N2 > √N), y puede encontrar divisores compuestos que antes no aparecían.

Con solo una iteración de bisección, el coste es bajo, y si el factor está en la zona adecuada, lo atrapa.

⚠️ Limitaciones
Si N es muy grande, siguiente_primo(N) puede ser costoso de calcular (pero se hace una sola vez).

Si el factor no está en el rango cubierto por la primera iteración de bisección, puede fallar incluso con la trampa.

La criba inicial (F0) y el k‑sweep (F1) se ejecutan siempre, lo que añade un coste fijo. Para pruebas rápidas, podrías desactivarlos, pero entonces perderías la capacidad de encontrar factores pequeños.

def siguiente_primo(inicio: int) -> int:
    """
    Dado un primo 'inicio', devuelve el siguiente primo.
    Funciona aunque inicio no sea primo (el algoritmo lo detecta).
    Basado en el método de acumuladores y 9 módulos del capítulo final.
    """
    if inicio < 2:
        return 2

    # Inicialización exacta como en el libro
    n = inicio
    m = n + 1
    ny = n - 1

    t = ny * ny
    tt = n * n
    nt = m * m

    n += 1
    m += 1
    ny += 1

    # Variables de memoria para los pasos de Karnaugh
    antp1 = False
    ant2p1 = False
    antp2 = False
    paso1 = False
    paso2 = False

    # Bucle infinito (hasta encontrar primo)
    while True:
        # 9 módulos
        t1 = t % ny
        t2 = t % n
        t3 = t % m
        tt1 = tt % ny
        tt2 = tt % n
        tt3 = tt % m
        nt1 = nt % ny
        nt2 = nt % n
        nt3 = nt % m

        # PASO 1 (se ejecuta durante 2 iteraciones)
        # Antes de actualizar, guardamos el estado anterior para que paso1 pueda
        # mantenerse activo durante 2 iteraciones.
        ant2p1 = antp1
        antp1 = (t3 > 0 and nt2 == 0)   # condición base

        # paso1 es verdadero si se cumple la condición base o alguna de las memorias
        paso1 = antp1 or antp1 or ant2p1   # (antp1 ya está, ant2p1 es la memoria de 2 pasos atrás)

        # PASO 2 (requiere que paso1 sea verdadero, y otras condiciones)
        if paso1 and t2 > 0 and tt2 > 0 and t3 == 0:
            antp2 = True
        else:
            antp2 = False

        paso2 = antp2   # paso2 se activa cuando se cumple la condición de paso2

        # PASO 3 (el decisivo)
        # Si paso2 es verdadero y se cumplen las condiciones finales, ny es primo
        if paso2 and t1 > 0 and (nt1 + nt2) == 0:
            # ¡Encontrado! ny es el siguiente primo
            return ny

        # Acumular los siguientes consecutivos
        t *= ny
        tt *= n
        nt *= m

        # Incrementar contadores
        ny += 1
        n += 1
        m += 1

        # Si ny supera un límite razonable, rompemos (por seguridad)
        if ny > 10**12:   # límite alto, pero evita bucles infinitos en caso de bug
            break

    # Fallback: si el algoritmo falla, usamos el método tradicional (por si acaso)
    # Esto nunca debería ocurrir si el algoritmo es correcto.
    return _siguiente_primo_tradicional(inicio)

                break

        n += 2

n es el número original (entrada). Lo llamaré N para evitar confusión.

p y q son factores primos de N (o tal vez primos consecutivos).

n' es el número modificado N' = N * sp donde sp es el siguiente primo de algún valor.

Dices: n' > n*n → N' > N^2.

raizn es √N.

p-q es la diferencia entre factores (gap). Pero cuidado: si p y q son primos, la diferencia podría ser positiva o negativa; normalmente q > p, así que q-p > 0.

Afirmas: raizn < p-q < n/2 → √N < q-p < N/2.

Luego: n' -> n > p-q && p-q < raizn'/2 → N' -> N > q-p && q-p < √N' / 2.

Vamos a analizar esto:

Primera condición: √N < q-p < N/2.

Esto significa que el gap entre los factores es mayor que la raíz cuadrada de N, pero menor que la mitad de N.

Si el gap es mayor que √N, entonces la búsqueda lineal desde p hasta q costaría más que √N pasos, por lo que la trampa de multiplicar por sp podría ser útil.

Segunda condición: N' > N^2.

Como N' = N * sp, esto implica sp > N. Es decir, el siguiente primo de N debe ser mayor que N (lo cual es cierto, ya que sp > N). De hecho, sp es al menos N+1, pero para que N' > N^2, necesitamos sp > N, lo cual siempre se cumple para N>1.

Tercera condición: N > q-p y q-p < √N' / 2.

N > q-p es trivial porque q-p es mucho menor que N (a menos que p sea muy pequeño, pero en general el gap es pequeño comparado con N).

q-p < √N' / 2 → Esto es una cota superior para el gap en términos de la raíz del número modificado. Si esta condición se cumple, entonces la búsqueda lineal sobre el gap q-p sería menor que la raíz de N', lo que sugiere que la trampa podría funcionar.

import math
import time

# ============================================================================
#  PARÁMETROS GLOBALES (ajustables)
# ============================================================================
PRIMOS     = [2, 3, 5, 7, 11, 13, 17, 19, 23]
PRIMORIAL  = math.prod(PRIMOS)
E_CONV     = (math.e - 1) / 2    # ≈ 0.8591
LIM_CRIBA  = 2_000_000
LIM_KSWEEP = 2_000_000
MAX_BISEC  = 8000                # Se sobreescribirá con max_bisec_iter
TALL_ASIM  = 4                   # 25% desde m_ini


# ============================================================================
#  BLOQUE 1: RODA PRIMORIAL
# ============================================================================

def pasa_rueda(m: int) -> bool:
    if m < 1:
        return False
    return math.gcd(2 * m + 3, PRIMORIAL) == 1


def proper_valid(m: int, pas: int = 1) -> int | None:
    for _ in range(500):
        if m < 1:
            return None
        if pasa_rueda(m):
            return m
        m += pas
    return None


# ============================================================================
#  BLOQUE 2: SIGNE DEL DESFASE ESPELL
# ============================================================================

def sgn_desfase(m: int, N: int) -> int:
    B = 2 * m + 3
    if B <= 1 or B >= N:
        return 0
    D_B = 2 * B
    R_B = N % D_B
    A = N // B
    if A < 3:
        return 0
    m_e = (A - 3) // 2
    if m_e < 1:
        return 0
    D_A = 2 * (2 * m_e + 3)
    R_A = N % D_A
    d = R_B * D_A - R_A * D_B
    return (1 if d > 0 else -1) if d != 0 else 0


def check_factor(m: int, N: int) -> bool:
    D = 2 * m + 3
    return D > 1 and D < N and (N % D == 0)


# ============================================================================
#  BLOQUE 3: K-SWEEP
# ============================================================================

def k_sweep(N: int, m_ini: int, m_fi: int) -> int | None:
    if m_ini < 1:
        m_ini = 1
    if m_fi < m_ini:
        return None
    k_lo = max(1, N // (2 * m_fi + 3))
    k_hi = N // (2 * m_ini + 3)
    for k in range(k_lo, k_hi + 1):
        if k <= 0:
            continue
        c = N // k
        if c < 3 or c % 2 == 0:
            continue
        if N % c == 0 and 1 < c < N:
            return c
    return None


# ============================================================================
#  BLOQUE 4: BISECCIÓN ASIMÉTRICA 25/75 (con límite de iteraciones)
# ============================================================================

def biseccio_asimetrica(N: int, m_ini: int, m_fi: int,
                         verbose: bool = False, max_iter: int = None) -> tuple[int | None, bool]:
    max_iters = max_iter if max_iter is not None else MAX_BISEC
    for it in range(max_iters):
        pos_i = 2 * m_ini + 3
        pos_f = 2 * m_fi + 3
        k_lo = max(1, N // pos_f) if pos_f > 0 else 1
        k_hi = N // pos_i if pos_i > 0 else 1
        n_k = k_hi - k_lo + 1

        if verbose:
            rang = m_fi - m_ini
            print(f"    {it:5d}: [{m_ini:>14,}, {m_fi:>14,}]  rang={rang:>12,}  n_k={n_k:>9,}")

        if n_k <= LIM_KSWEEP:
            return k_sweep(N, m_ini, m_fi), False

        rang = m_fi - m_ini
        m_25 = proper_valid(m_ini + rang // TALL_ASIM, 1)
        m_e = proper_valid(m_ini, 1)
        m_d = proper_valid(m_fi, -1)

        if not (m_e and m_25 and m_d):
            return k_sweep(N, m_ini, m_fi), False

        for mp in [m_e, m_25, m_d]:
            if check_factor(mp, N):
                return 2 * mp + 3, False

        s_e = sgn_desfase(m_e, N)
        s_25 = sgn_desfase(m_25, N)
        s_d = sgn_desfase(m_d, N)

        if verbose:
            print(f"          s_e={s_e:+d}  s_25={s_25:+d}  s_d={s_d:+d}  (punts: {m_e:,} | {m_25:,} | {m_d:,})")

        if s_e != 0 and s_25 != 0 and s_e != s_25:
            if verbose:
                print(f"          → Canvi [0-25%]: bisectem rang × 0.25")
            m_fi = m_25
        elif s_25 != 0 and s_d != 0 and s_25 != s_d:
            if verbose:
                print(f"          → Canvi [25-100%]: bisectem rang × 0.75")
            m_ini = m_25
        else:
            if verbose:
                print(f"          → Sense canvi de signe: factor prop de √N, cobert per F1")
            return None, True

    return None, False

#  BLOQUE 5: ORQUESTRADOR MDC v23 (con límite de iteraciones)
# ============================================================================

def mdc_v23(N: int, verbose: bool = True, max_bisec_iter: int = None) -> tuple:
    if verbose:
        bar = '═' * 72
        print(f"\n{bar}")
        print(f"  MDC v23 — Bisecció Asimètrica 25/75")
        print(f"  Tall al 25% (lluny de √N) · Si no hi és → ja és a √N")
        print(f"  N = {N:,}")
        print(f"  ({len(str(N))} dígits  |  {N.bit_length()} bits)")
        print(f"{bar}")

    t0 = time.perf_counter()

    # F0: CRIBA RODA
    if verbose:
        print(f"\n  [F0] Criba roda fins m={LIM_CRIBA:,}...")

    for p in PRIMOS:
        if N % p == 0 and p < N:
            t_ms = (time.perf_counter() - t0) * 1000
            if verbose:
                print(f"    → Factor primorial: {p}")
            return p, t_ms

    r = math.isqrt(N)
    if r * r == N:
        t_ms = (time.perf_counter() - t0) * 1000
        if verbose:
            print(f"    → Quadrat perfecte: {r}")
        return r, t_ms

    m_max = (math.isqrt(N) - 3) // 2
    lim_c = min(m_max, LIM_CRIBA)

    for m_c in range(1, lim_c + 1):
        if pasa_rueda(m_c):
            D = 2 * m_c + 3
            if N % D == 0 and D < N:
                t_ms = (time.perf_counter() - t0) * 1000
                if verbose:
                    print(f"    → Factor criba: {D:,}")
                return D, t_ms

    if lim_c >= m_max:
        t_ms = (time.perf_counter() - t0) * 1000
        if verbose:
            print(f"    → Criba cobreix tot el rang.")
        return None, t_ms

    t_c = (time.perf_counter() - t0) * 1000
    if verbose:
        print(f"    → {t_c:.1f} ms. m_max={m_max:,}")

    # F1: K-SWEEP PROP √N
    k_top = max(1, N // (2 * m_max + 3))
    k_lim = k_top + LIM_KSWEEP
    d_lim = N // k_lim if k_lim > 0 else 2 * m_max + 3
    m_lim = max(lim_c + 1, (d_lim - 3) // 2)

    if verbose:
        print(f"\n  [F1] K-sweep [{m_lim:,}, {m_max:,}]  (~{LIM_KSWEEP:,} k)...")

    factor = k_sweep(N, m_lim, m_max)
    if factor:
        t_ms = (time.perf_counter() - t0) * 1000
        _print(N, factor, "F1 k-sweep √N", t_ms, verbose)
        return factor, t_ms

    t_f1 = (time.perf_counter() - t0) * 1000
    if verbose:
        print(f"    → {t_f1:.1f} ms. Res trobat.")

    # F2: BISECCIÓ ASIMÈTRICA 25/75
    m_conv_val = max(lim_c + 1, int(E_CONV * m_max))

    if verbose:
        rang = m_conv_val - lim_c
        n_pit = max(1, round(math.log(max(2, rang / LIM_KSWEEP), 4)))
        print(f"\n  [F2] Bisecció asimètrica 25/75 [{lim_c:,}, {m_conv_val:,}]")
        print(f"    → Rang: {rang:,}  ({rang.bit_length()} bits)")
        print(f"    → Pitjor cas: ~{n_pit} talls (sempre al 25% inferior)")
        print(f"    → Cas típic: menys talls (quan cau al 75% → prop √N → fi)")

    factor, es_f1 = biseccio_asimetrica(N, lim_c, m_conv_val,
                                        verbose=verbose,
                                        max_iter=max_bisec_iter)

    t_ms = (time.perf_counter() - t0) * 1000

    if factor:
        _print(N, factor, "F2 bisecció asimètrica", t_ms, verbose)
        return factor, t_ms

    if es_f1 and verbose:
        print(f"\n  ℹ️  La bisecció confirma: factor és prop de √N.")
        print(f"     (F1 ja l'ha cobert, o N és primer en aquest rang.)")

    if verbose:
        print(f"\n  ✗ No trobat. Temps: {t_ms:.2f} ms")
    return None, t_ms


def _print(N, f, zona, t_ms, verbose):

    bar = '═' * 72

    print(f"  🎯 [{zona}]")
    print(f"     p = {f:,}")

    print(f"     t = {t_ms:.3f} ms")

def siguiente_primo(inicio: int) -> int:
    """Algoritmo del Libro 2 con acumuladores y 9 módulos (Karnaugh)."""
    if inicio < 2:
        return 2

    n = inicio
    m = n + 1
    ny = n - 1

    t = ny * ny
    tt = n * n
    nt = m * m

    ant_p1 = False
    ant2_p1 = False
    ant_p2 = False

    MAX_ITER = 10_000_000
    iter_count = 0

    while True:
        iter_count += 1
        if iter_count > MAX_ITER:
            return _siguiente_primo_tradicional(inicio)

        t_mod_ny = t % ny if ny != 0 else 0
        t_mod_n  = t % n  if n  != 0 else 0
        t_mod_m  = t % m  if m  != 0 else 0

        tt_mod_ny = tt % ny if ny != 0 else 0
        tt_mod_n  = tt % n  if n  != 0 else 0
        tt_mod_m  = tt % m  if m  != 0 else 0

        nt_mod_ny = nt % ny if ny != 0 else 0
        nt_mod_n  = nt % n  if n  != 0 else 0
        nt_mod_m  = nt % m  if m  != 0 else 0

        # PASO 1
        paso1_actual = (t_mod_m > 0) and (nt_mod_n == 0)
        ant2_p1 = ant_p1
        ant_p1  = paso1_actual
        paso1   = paso1_actual or ant_p1 or ant2_p1

        # PASO 2
        paso2_actual = paso1 and (t_mod_n > 0) and (tt_mod_n > 0) and (t_mod_m == 0)
        ant_p2 = paso2_actual
        paso2  = paso2_actual

        # PASO 3 (decisión)
        if paso2 and (t_mod_ny > 0) and ((nt_mod_ny + nt_mod_n) == 0):
            return ny

        t *= ny
        tt *= n
        nt *= m

        ny += 1
        n  += 1
        m  += 1

        if ny > inicio + 10**6:
            return _siguiente_primo_tradicional(inicio)


def _siguiente_primo_tradicional(n: int) -> int:
    """Fallback: fuerza bruta (solo para emergencias)."""
    if n < 2:
        return 2
    n = n + 1 if n % 2 == 0 else n + 2
    while True:
        if all(n % p != 0 for p in range(3, int(math.isqrt(n)) + 1, 2)):
            return n
        n += 2

def buscar_factor_con_trampa(N: int, max_iter: int = 1, verbose: bool = False):
    t0 = time.perf_counter()

    if verbose:
        print(f"\n[+] Intento 1: mdc_v23({N}) con {max_iter} iteración(es)")

    factor1, t1 = mdc_v23(N, verbose=verbose, max_bisec_iter=max_iter)
    if factor1 is not None:
        t_ms = (time.perf_counter() - t0) * 1000
        return factor1, N, t_ms

    sp = siguiente_primo(N)
    N2 = N * sp
    if verbose:
        print(f"\n[+] Intento 2: mdc_v23({N2}) con {max_iter} iteración(es)")
        print(f"    sp = {sp}")

    factor2, t2 = mdc_v23(N2, verbose=verbose, max_bisec_iter=max_iter)

    if factor2 is not None and math.gcd(N, factor2) > 1:
        t_ms = (time.perf_counter() - t0) * 1000
        return factor2, N2, t_ms

    t_ms = (time.perf_counter() - t0) * 1000
    return None, None, t_ms

def _siguiente_primo_tradicional(n: int) -> int:
    if n < 2:
        return 2
    n = n + 1 if n % 2 == 0 else n + 2
    while True:
        if all(n % p != 0 for p in range(3, int(math.isqrt(n)) + 1, 2)):
            return n
        n += 2

    t0 = time.perf_counter()
    sp = siguiente_primo(N)
    t_sp = (time.perf_counter() - t0) * 1000

    print(f"\n[3] MDC v23 con 1 iteración sobre N*sp (CON TRAMPA)")
    factor2, t2 = mdc_v23_limited(N2, max_bisec_iter=max_iter, verbose=verbose)

    if factor2:

        else:
            print(f"    ❌ factor {factor2} no divide a N (descartado)")
    else:
        print(f"    ❌ No encontrado en {t2:.2f} ms")

    return None, t1 + t2, sp

# -*- coding: utf-8 -*-
"""
==============================================================================
  KSWEEP + TRAMPA DEL SIGUIENTE PRIMO (LIBRO 2)
  ==========================================================================
  Estrategia:
    1. ksweep(N) → busca factor pequeño en N.
    2. Si falla → sp = siguiente_primo(N) (Libro 2).
    3. ksweep(N * sp) → busca factor en N*sp.
    4. Si encuentra f, comprueba mcd(N, f) > 1 → f es factor de N.
    5. El otro factor es q = N // f.
==============================================================================
  AUTOR : Víctor Manzanares Alberola (adaptación)
==============================================================================
"""

import math
import time

# ============================================================================
# 1. KSWEEP (el original, sin bisección)
# ============================================================================

def ksweep(N: int, m_ini: int = 1, m_fi: int = None) -> int | None:
    """
    Busca el factor más pequeño de N en el rango [m_ini, m_fi].
    Si m_fi es None, se usa √N.
    """
    if m_fi is None:
        m_fi = (math.isqrt(N) - 3) // 2
    if m_ini < 1:
        m_ini = 1
    if m_fi < m_ini:
        return None

    # Convertir rango de m a rango de k
    k_lo = max(1, N // (2 * m_fi + 3))
    k_hi = N // (2 * m_ini + 3)

    for k in range(k_lo, k_hi + 1):
        if k <= 0:
            continue
        c = N // k
        if c < 3 or c % 2 == 0:
            continue
        if N % c == 0 and 1 < c < N:
            return c  # factor encontrado
    return None

# ============================================================================

    """Algoritmo exacto del Libro 2: Números otra vez."""
    if inicio < 2:

    n = inicio
    m = n + 1
    ny = n - 1

def buscar_factor_con_trampa(N: int, verbose: bool = False):

    if verbose:

    # Intento 2: trampa con sp

def ksweep_secuencia_minimos(N, m_ini=1, m_fi=None):
    if m_fi is None:
        m_fi = (math.isqrt(N) - 3) // 2
    
    espacio = m_fi - m_ini
    # Generar los m candidatos usando la secuencia de mínimos
    # pero desde el lado izquierdo (factores pequeños) y derecho (espejo)
    candidatos = set()
    
    # Gravedad izquierda: m = m_ini + espacio/i!  (o divisores armónicos)
    divisor = 2
    while True:
        salto = espacio // divisor
        if salto < 1: break
        m_cand = m_ini + salto
        if m_cand >= m_ini and m_cand <= m_fi:
            candidatos.add(m_cand)
        divisor += 1
    
    # Gravedad derecha: m = m_fi - espacio/i!
    divisor = 2
    while True:
        salto = espacio // divisor
        if salto < 1: break
        m_cand = m_fi - salto
        if m_cand >= m_ini and m_cand <= m_fi:
            candidatos.add(m_cand)
        divisor += 1
    
    # Ahora, en lugar de barrer todos, solo iteramos sobre los candidatos
    for m in sorted(candidatos):
        D = 2*m + 3
        if N % D == 0:
            return D  # Factor directo
        # Calcular espejo
        B = N // D
        m_esp = (B - 3) // 2
        if m_esp < 1: continue
        # Calcular fase y vector director (usando d_frac y vector_director)
        fase_m = d_frac(m, N)
        fase_esp = d_frac(m_esp, N)
        # Si las fases son cercanas (resonancia), calcular salto
        if abs(fase_m - fase_esp) < 0.01:

            resto = N % D
            offset = (D - N + resto/(D-1)) / 2
            m_salto = m - int(offset)
            if m_salto >= m_ini and m_salto <= m_fi:
                D_salto = 2*m_salto + 3
                if N % D_salto == 0:
                    return D_salto

PRIMOS = [2, 3, 5, 7, 11, 13, 17, 19, 23]
PRIMORIAL = math.prod(PRIMOS)

def pasa_rueda(m):
    return math.gcd(2 * m + 3, PRIMORIAL) == 1

def alinear_rueda(m):
    while m >= 1 and not pasa_rueda(m):
        m -= 1
    return m if m >= 1 else None

def generar_pilares_secuencia(N, m_ini=1, m_fi=None):
    """Genera pilares usando la secuencia telescópica n = n * (i-2)/i."""
    if m_fi is None:
        m_fi = (math.isqrt(N) - 3) // 2
    espacio = m_fi - m_ini
    pilares = set()
    
    # Aplicamos la secuencia: valor = valor * (i-2)/i
    # Comenzamos con el espacio total, i=3 da espacio/3
    valor = espacio
    i = 3

            if m_valid and m_ini <= m_valid <= m_fi:
                pilares.add(m_valid)
        i += 1
    
    # Añadir los extremos
    pilares.add(m_ini)
    pilares.add(m_fi)
    return sorted(pilares)

# =====================================================================
def tejer_red_intersticial(pilares, densidad=1000):
    red = set(pilares)
    for i in range(len(pilares) - 1):
        p1, p2 = pilares[i], pilares[i+1]
        gap = p2 - p1
        if gap > densidad:
            paso = gap // densidad
            for j in range(1, densidad):
                m = p1 + j * paso
                m_valid = alinear_rueda(m)
                if m_valid:
                    red.add(m_valid)
        else:
            for m in range(p1 + 1, p2):
                m_valid = alinear_rueda(m)
                if m_valid:
                    red.add(m_valid)
    return sorted(red)

def filtrar_zonas_calientes(N, red_m, limite_zonas=100):

        if pos <= 1:

        profundidad = minimo_recta / pos

        y = math.isqrt(delta)
        if y * y == delta:
            factor_fermat = x - y
            if factor_fermat > 1 and factor_fermat != N:
                return factor_fermat, "Fermat (S±k)"
    return None, None

      5. Si falla, sp = siguiente_primo(N) y repetir con N*sp.

    # Fase 3: Filtrar

    # Fase 4: Impacto dual con búsqueda local
    for m, pos, variacion in zonas_calientes:

            m_test = m + offset
            if m_test < m_ini or m_test > m_fi:
                continue

                return D_test, N // D_test, None, t

def ksweep_pilares(N, m_ini=1, m_fi=None, ventana=2000):

def ksweep_pilares(N, m_ini=1, m_fi=None, ventana=2000):
    if m_fi is None:
        m_fi = (math.isqrt(N) - 3) // 2
    espacio = m_fi - m_ini
    pilares = set()
    # Generar pilares con la secuencia n/i!
    divisor = 2
    fact = 2
    while True:
        salto = espacio // fact
        if salto < 1:
            break
        m1 = m_ini + salto
        m2 = m_fi - salto
        for m in (m1, m2):
            if m_ini <= m <= m_fi:
                pilares.add(m)
        divisor += 1
        fact *= divisor
    # Buscar en vecindad de cada pilar
    for p in pilares:
        for offset in range(-ventana, ventana+1):
            m = p + offset
            if m < m_ini or m > m_fi:
                continue
            D = 2*m + 3
            if N % D == 0 and D != 1 and D != N:
                return D
    return None

            # Descartar: podría ser sp o un factor de sp
            if verbose:
                print(f"      ❌ factor {f2} no divide a N o es sp")
    return None, None, None, tiempo
Además, en ksweep_pilares debes asegurarte de que el factor encontrado sea divisor de N (no de N*sp). Si ksweep_pilares se ejecuta sobre N2, puede devolver sp porque sp divide a N2. La verificación N % f2 == 0 es la que filtra.

🧪 Integración de la secuencia de mínimos en ksweep
Tu secuencia n = n*(i-2)/i es equivalente a la serie armónica inversa n/i (como bien dedujiste). Para generar pilares de forma eficiente, usa:

python
def generar_pilares_armonicos(N, m_ini=1, m_fi=None, usar_factorial=True):
    if m_fi is None:
        m_fi = (math.isqrt(N) - 3) // 2
    espacio = m_fi - m_ini
    pilares = set()
    if usar_factorial:
        fact = 2
        i = 2
        while True:
            salto = espacio // fact
            if salto < 1:
                break
            pilares.add(m_ini + salto)
            pilares.add(m_fi - salto)
            i += 1
            fact *= i
    else:
        # Versión simple: n/i
        for i in range(2, int(math.log2(espacio)) + 10):
            salto = espacio // i
            if salto < 1:
                break
            pilares.add(m_ini + salto)
            pilares.add(m_fi - salto)
    return sorted(pilares)
Luego, en ksweep_pilares, itera sobre estos pilares y sus vecinos con una ventana fija (ej. 2000). Eso te dará un barrido O(log N).
