1. DEFINICIONES (modelo ME / MEcuation)
--------------------------------------------------------------------------------

  Φ(E) = vector de features sobre instancia E (logs, distancias a potencias, etc.)

  ME LOCAL en ventana W:
    ∃ colapso de rango: en ≥ consensus% réplicas bootstrap,
    κ = σ_min(Y_c) / σ_max(Y_c) < τ
    donde Y_c = matriz de features centrada, con ruido ±ε por observación.

  ME GLOBAL:
    El mismo colapso sobre W₁ ∪ W₂ ∪ … (todas las ventanas mezcladas).

  NO-UNIFICACIÓN (certificada en el modelo):
    ∃ ventanas con ME local = Sí  Y  ME global = No

--------------------------------------------------------------------------------
2. MATEMÁTICA ÚTIL (no tautológica)
--------------------------------------------------------------------------------

  Features básicas (cuadrados perfectos E = p²):
    f₁(E) = log E
    f₂(E) = log √E = ½ log E
    f₃(E) = f₁ − 2f₂ ≡ 0   (tautología algebraica)

  Observación clave: para E = p²,
    (f₁, f₂, f₃) = (2 ln p, ln p, 0) = ln p · (2, 1, 0)
    ⇒ subespacio efectivo dimensión 1 (colinealidad).

  Features extendidas (me_local_test.py) para separar régimen cuadrático vs cúbico:
    f₁ = log E
    f₂ = log(1 + |E^(1/2) − round(E^(1/2))|)
    f₃ = log(1 + |E^(1/3) − round(E^(1/3))|)
    f₄ = log(1 + |E^(1/5) − round(E^(1/5))|)
    f₅ = log(max(d₂,d₃) / min(d₂,d₃))

  Criterio colapso: κ_rel = σ_min / σ_max < τ  (τ ≈ 1e-6 … 5e-3 según script)

  Bootstrap con incertidumbre:
    Para cada réplica s = 1..N:
      y_i^(s) ~ Uniform(y_i − ε_i, y_i + ε_i)
      E_i^(s) = exp(y_i^(s))
      fila_i = Φ(E_i^(s))
