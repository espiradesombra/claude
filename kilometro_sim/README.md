## Protocolo estrella (VMA)

> Bajada **media lineal** (generador) + media **rotatoria** (robar/rearmar distancia) + **rearme cada N impar** por **flotación + perneo**.  
> “Hurto gravitatorio” posible pero muy complicado; rol estrella en renovables = batería de lastre **y** convertidor de fase.
