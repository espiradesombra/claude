EliminaDuplicados K3
====================

GUI portable basada en el hash K3 de HASHTOOLCODE (misma lógica que k3dedup.c).

Uso
---
1. Abre EliminaDuplicadosK3.exe
2. Examinar… → elige carpeta
3. Escanear
4. Revisa: verde = conservar; naranja = candidato a borrar (☑)
5. Doble clic / Espacio para marcar o desmarcar
6. "Eliminar marcados…" → confirmación 1/2 → escribe BORRAR

Nunca borra todas las copias de un grupo: siempre queda ≥1.

Origen
------
Carpeta HASHCODETOOLS del Escritorio (k3hash.zip descomprimido).
Fuente: elimina_duplicados_k3.py
