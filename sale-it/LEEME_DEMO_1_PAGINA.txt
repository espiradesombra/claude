REQUISITOS
  Windows 10/11 · Python 3.10+ (probado 3.12) · sin pip extra

DEMO EN 3 PASOS (doble clic o terminal)
  1) scripts\01_instalar.bat          → comprueba Python
  2) scripts\05_verificar_k3.bat      → 5 digests K3 [OK]
  3) scripts\03_benchmark_udp.bat     → arquitecturas A…E (el bueno es E)

  Manual equivalente:
    cd sale-it\src\antipc
    python verify_k3.py
    python benchmark.py --udp --packets 1000 --payload 64 --hubs 4
