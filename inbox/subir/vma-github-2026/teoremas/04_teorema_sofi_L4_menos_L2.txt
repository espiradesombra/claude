--------------------------------------------------------------------------------
ESTRUCTURA SOFÍ (DEFINICIONES)
--------------------------------------------------------------------------------
  L1  = { a ∈ ℕ : a ≡ 5 (mod 6) }
  L3  = { a ∈ L1 : a = (6k−1)(6h+1) }
  L4  = { a ∈ L1 : 2a+1 = (6j−1)(6g+1) }
  L2  = L3 ∩ L4
  LSG = { p ∈ L1 : p y 2p+1 primos }
  U2  = L1 \ (L3 ∪ L4)

--------------------------------------------------------------------------------
TEOREMA (del TXT)
--------------------------------------------------------------------------------
  L4 \ L2 es infinito.

Idea de prueba:
  Para primo q ≥ 5, imponer p ≡ 5 (mod 6) y 2p+1 ≡ 0 (mod q).
  ⇔ p ≡ (q−1)/2 (mod q).
  Por TCR existe clase r (mod 6q); por Dirichlet, infinitos primos p ≡ r.
  Tales p ∈ L4 y ∉ L3.
