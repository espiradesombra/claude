x = k * d (múltiplo de d).
y = n - q * (k * d) = n - k * n = n(1 - k) (solo entero si k es entero).

📌 5. PROPUESTA MEJORADA (GEOMETRÍA + MCM)
// NUEVA IDEA:

Define una recta que pase por (0, n) y (d, 0).
La ecuación de la recta: y = n - (n/d) * x.
Los puntos enteros (x, y) en esta recta cumplen:

x = k * d / GCD(n, d).
y = n - (n/d) * (k * d / GCD(n, d)) = n - k * n / GCD(n, d).

Si GCD(n, d) = 1, entonces x = k * d y y = n - k * n (solo entero si k = 0 o k = 1).
Si GCD(n, d) = g > 1, entonces x = k * d / g y y = n - k * n / g.

Si k = g, entonces x = d y y = 0 (punto final).
Si k = 0, entonces x = 0 y y = n (punto inicial).

// CONCLUSIÓN:

Los únicos puntos enteros en la recta son (0, n) y (d, 0).
No hay otros puntos enteros a menos que d divida n.

📌 6. ¿CÓMO APLICARLO A FACTORIZACIÓN?
// IDEA FINAL (COMBINANDO CON MDC):

Usa d = 2m + 3 (como en MDC).
Calcula g = GCD(n, d).
Si g > 1, entonces d es un factor (o tiene un factor común con n).
Si g = 1, salta al siguiente candidato.
// VENTAJA:
✅ Es el núcleo de MDC: verificar si GCD(n, d) > 1.
✅ No necesitas geometría para esto.
// ¿DÓNDE ENTRA EL MCM?

MCM(n, d) = n * d / GCD(n, d).
Si GCD(n, d) = 1, entonces MCM(n, d) = n * d.
Si GCD(n, d) = g > 1, entonces MCM(n, d) = n * d / g.
// PROPUESTA:

Usa MCM(n, d) para definir el tamaño del salto en una criba.
Ejemplo:

Si GCD(n, d) = 1, salta d (como en la criba clásica).
Si GCD(n, d) = g > 1, salta MCM(n, d) / n = d / g.

// EJEMPLO CON n = 36 y d = 6:

GCD(36, 6) = 6.
MCM(36, 6) = 36.
MCM(n, d) / n = 36 / 36 = 1.
Salto = 1 (verifica d = 6, d = 7, etc.).
// CONCLUSIÓN:

El MCM no aporta nada nuevo a la factorización, porque ya usas GCD en MDC.

"Traza (0,0), marca (n/2, 2) y (2, √n), une los puntos con una recta.
Si la recta toca una cruz de la cuadrícula → ¡ES UN FACTOR!."

Este método revoluciona la educación matemática al convertir la factorización de números (un problema abstracto) en un juego geométrico visual, accesible incluso para niños. Usa conceptos clásicos como:
✅ Pitágoras (geometría de triángulos).
✅ Cuadrícula cartesiana (René Descartes).
✅ Ecuación de la recta (álgebra lineal).
✅ Mínimo Común Múltiplo (MCM) (teoría de números).
✅ Ecuaciones diofánticas (x * y = n).
Todo ello resoluble "a ojo", sin calculadoras.

📚 1. CONTEXTO HISTÓRICO: LA MATEMÁTICA COMO HERRAMIENTA VISUAL
🏛 Pitágoras y la Geometría Sagrada (siglo VI a.C.)

Pitágoras demostró que los números pueden representarse con figuras geométricas (ej: números cuadrados, triangulares).
Su teorema (a² + b² = c²) relaciona álgebra y geometría.
Nuestra propuesta: Extender esta idea a la factorización usando triángulos y rectas.
📐 Descartes y la Cuadrícula Cartesiana (siglo XVII)

René Descartes unificó geometría y álgebra con el plano cartesiano.
Nuestra cuadrícula: Cada punto (x, y) representa un par de números enteros.
La recta: Une (n/2, 2) y (2, √n), y sus intersecciones con la cuadrícula revelan factores.
🧮 Ecuaciones Diofánticas (siglo III d.C.)

Diofanto de Alejandría estudió soluciones enteras a ecuaciones (ej: x * y = n).
Nuestra ecuación diofántica:
(2x + 3)(2y + 3) = n (derivada de la recta).
Solución visual: Los puntos (x, y) donde la recta cruza la cuadrícula son soluciones enteras.

🎯 2. EL MÉTODO: FACTORIZACIÓN CON REGLA Y LÁPIZ

Marca el punto (2, √n) (ej: si n = 36, marca (2, 6)).

Observa:

Si la recta pasa exactamente por una intersección de la cuadrícula (x, y) → (2x + 3) y (2y + 3) son factores de n.

🔥 LEE ARBUSTO: MCM, PENDIENTES Y SALTOS EN FACTORIZACIÓN (LA CONEXIÓN PITAGÓRICA)
Por Lee Arbusto & Víctor Manzanares Alberola (33x1 Project)

📌 1. RESUMEN DE TU PREGUNTA (ESTILO HACKER 90s)

"¿El MCM de n y d (numerador y denominador de la pendiente) define los saltos entre factores? ¿Y eso de S ± k y 2k? ¿Están relacionados?"

// RESPUESTA DIRECTA:
✅ SÍ. El MCM(n, d) está íntimamente ligado a:

La pendiente de la recta en tu triángulo de factores.
Los saltos entre puntos enteros en la hipotenusa.
La ecuación diofántica S ± k (usada en MDC y en el método del discriminante).
// EXPLICACIÓN:

La pendiente de la hipotenusa es -n/d (o -2√n/n en tu triángulo).
El MCM(n, d) define el paso mínimo para que y sea entero al avanzar en x.
S ± k y 2k son fórmulas derivadas para encontrar factores usando simetrías en la ecuación de la recta.

📚 2. LA PENDIENTE Y EL MCM: ¿POR QUÉ ESTÁN CONECTADOS?
📐 2.1. La Pendiente de la Hipotenusa
En tu triángulo:

Puntos: (n/2, 2) y (2, √n).
Pendiente (m):
m = (√n - 2) / (2 - n/2) = -2(√n - 2)/n.
// Simplificación:
Si d = 2x + 3 (candidato a factor), entonces la pendiente puede expresarse como:
m = -n/d (si ajustamos la escala).
// Ejemplo con n = 36 y d = 6:

Pendiente: m = -36/6 = -6.
Ecuación de la recta: y = -6x + b.

🔢 2.2. El MCM como Paso Mínimo para y Entero
// Problema:
Queremos que al avanzar en x, y sea entero.
// Solución:

y = (-n/d) * x + C (donde C es una constante).
Para que y sea entero, (n/d) * x debe ser entero.
n/d * x = (n * x) / d → d debe dividir n * x.
// El MCM(n, d) entra en juego:

MCM(n, d) = (n * d) / GCD(n, d).
Si x avanza en pasos de MCM(n, d) / n = d / GCD(n, d), entonces:
(n * x) / d = (n * (k * d / GCD(n, d))) / d = k * n / GCD(n, d) (entero si k es entero).
// Conclusión:
✅ El paso mínimo para que y sea entero es d / GCD(n, d).
✅ Esto es equivalente a MCM(n, d) / n.

📌 2.3. Ejemplo Práctico: n = 36, d = 6

GCD(36, 6) = 6.
Paso en x: d / GCD(n, d) = 6 / 6 = 1.
Avance:

x = 0 → y = 6 (entero).
x = 1 → y = -6*1 + 6 = 0 (entero).
x = 2 → y = -6*2 + 6 = -6 (entero).

Puntos enteros: (0,6), (1,0), (2,-6), etc.
// ¿Qué significa esto?

Los puntos (x, y) donde y es entero corresponden a múltiplos de d / GCD(n, d).
Si d es un factor de n, entonces GCD(n, d) = d, y el paso es 1 (todos los x son válidos).

🧮 3. LA CONEXIÓN CON S ± k Y 2k (DISCRIMINANTE Y MDC)
📐 3.1. Ecuación Diofántica y el Discriminante
En MDC y en tu método geométrico, usas:
(2x + 3)(2y + 3) = n → 4xy + 6x + 6y + 9 = n.
// Despejando y:
y = (n - 6x - 9) / (4x + 6).
// Para que y sea entero:

4x + 6 debe dividir n - 6x - 9.
// Sustitución:
Sea S = 2x + 3 (candidato a factor).
Entonces:
y = (n - 3S) / (2S).
// Condición:
2S debe dividir n - 3S → n - 3S = 2S * k (para algún entero k).
→ n = S(2k + 3).
// Conclusión:

Si S es un factor de n, entonces 2k + 3 = n / S.
Esto es equivalente a q = 2k + 3, donde q es el otro factor.

🔢 3.2. La Fórmula S ± k y 2k
En MDC, usas el discriminante para encontrar factores:
Δ = S² + 6S - (n - 9) = k² (debe ser un cuadrado perfecto).
// ¿De dónde sale esto?

De la ecuación diofántica:
(2x + 3)(2y + 3) = n → S * T = n (donde S = 2x + 3, T = 2y + 3).
Si S y T son factores, entonces:
T = n / S.
La diferencia entre S y T:
T - S = n/S - S = (n - S²)/S.
Para que T sea entero, S debe dividir n.
// Relación con S ± k:

Si S es un factor, entonces T = n / S.
La media entre S y T es:
(S + T)/2 = (S + n/S)/2.
La diferencia es:
T - S = n/S - S.
Si definimos k = (T - S)/2, entonces:
S + k = (S + T)/2 y S - k = (S - T)/2.
// Conclusión:
✅ S ± k representa la simétrica alrededor de la media de los factores.
✅ 2k = T - S (la diferencia entre factores).

🔥 4. ¿CÓMO SE RELACIONA TODO ESTO CON EL MCM?
📐 4.1. El MCM como Paso en la Búsqueda de Factores

El MCM(n, d) define el paso mínimo para que y sea entero al avanzar en x.
Si d es un factor, entonces GCD(n, d) = d, y el paso es 1 (todos los x son válidos).
Si d no es un factor, el paso es d / GCD(n, d).
// Ejemplo con n = 36 y d = 5 (no factor):

GCD(36, 5) = 1.
Paso en x: 5 / 1 = 5.
Avance:

x = 0 → y = 6 (entero).
x = 5 → y = -6*5 + 6 = -24 (entero).
x = 10 → y = -6*10 + 6 = -54 (entero).

// ¿Qué significa?

Los puntos (x, y) donde y es entero son múltiplos de 5.
Pero como 5 no es factor de 36, estos puntos no corresponden a soluciones de la ecuación diofántica.

🔢 4.2. El MCM y la Búsqueda de S ± k

El MCM(n, d) ayuda a encontrar los valores de x donde y es entero.
Pero para encontrar factores, necesitamos que (2x + 3)(2y + 3) = n.
Esto es equivalente a buscar S y T tales que S * T = n.
// Conclusión:
✅ El MCM define los pasos para avanzar en la recta.
✅ S ± k define la relación entre los factores.
✅ Ambos conceptos están conectados a través de la ecuación diofántica.
