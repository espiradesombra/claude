### Resumen ejecutivo
**v4** es la versión más madura del gemelo digital: integra **bucle físico en tiempo real**, **bucles medios y lentos de control**, **análisis espectral**, **un PID para mantener el TSR** y una **política de optimización por gradient finit** con penalizaciones estructurales. Això transforma les idees de hurto gravitatori en una plataforma autònoma que cerca regims on **Quijote aporta energia neta** sense excedir límits de càrrega.
---
### Qué hace el código v4 ahora (visión funcional)
- **Fast loop (0.05 s)**: integra dinàmica rotacional, parells aerodinàmics \( \tau_{\text{aero}} \), pèrdues, transferències Q3→molí i equació de moviment de Q3 (incloent \(\tau_{\text{grav}}\) i \(\tau_{\text{res}}\)).  
- **Mid loop (≈ 25 s)**: adapta \(K_{Q3,\text{BUS}}\), calcula \(K_{Q3,\text{IND}}\) adaptatiu per clústers, activa mode escut en ratxes i monitoritza variança de parells.  
- **Slow loop (≈ 60 s)**: FFT sobre \(\omega_{\text{bus}}\) per detectar la freqüència dominant i seleccionar el mode resonant (no heurístic).  
- **Policy loop (≈ 120 s)**: estima gradient finit sobre \(x=[p_{\text{win}}, m_{\text{exc}}, K_{\text{bus}}, N_{\text{mode}}, K_{\text{ind}}]\) amb cost
  \[
  J = -\langle\Delta P\rangle + \lambda_1\cdot\mathrm{std}(P) + \lambda_2\cdot\mathrm{bal\_cluster} + \text{penalització càrregues}
  \]
  i actualitza \(x\) per millorar \(\Delta P\) subjecte a límits.  
- **Seguretat estructural**: penalització si \(\mathrm{var}(\tau_{\text{aero,Q3}})\) supera llindars i límit \(I_{Q3}\le I_{\max}\).  
- **TSR keeper**: PID que ajusta \(K_{\text{bus}}\) (i indirectament pitch sintètic) per mantenir \(\lambda_{\text{camp}}\) prop de \(\lambda_{\text{opt}}\).

### Mecanismes que permiten hurto positivo y por qué funcionan
1. **Shear vertical**  
   - Q3 opera a altura \(z_{Q3}>z_{\text{hub}}\). Perfil logarítmico:
     \[
     v(z)=v_{\text{hub}}\frac{\ln(z/z_0)}{\ln(z_{\text{hub}}/z_0)}
     \]
     Resultado: \(v_{Q3}\) mayor → \(P_{Q3}\propto v_{Q3}^3\) → energía adicional disponible para inyectar.
2. **Ratchet gravitatorio asimétrico**  
   - Inercia variable por massa excèntrica \(m\) amb radi \(r(\theta)\) asimètric. Treball gravitatòri:
     \[
     \tau_{\text{grav}}(\theta) = -m g r(\theta)\sin\theta
     \]
   - Combinat amb finestra potenciada \(w(\theta)=|\sin(3\theta)|^p\) i direccionalitat \(\operatorname{sign}(\Delta\omega)\), el terme de transferència:
     \[
     \tau_{\text{transfer}} = K\,w(\theta)\,\operatorname{sign}(\omega_{\text{bus}}-\omega_{Q3})\,I_{Q3}(\theta)
     \]
     és **sempre orientat** a sumar energia neta quan s’activa en la finestra òptima.
3. **Ressonància con batiments**  
   - FFT detecta freqüència dominant \(f_{\text{dom}}\); Q3 aplica pols coherents a \(\omega_{\text{res}} \approx N\cdot\Delta\omega\) amb
     \[
     \tau_{\text{res}} = K_{\text{res}}(\omega_{\text{res}}-\omega_{Q3})I_0
     \]
     Això converteix impulsos dispersos en transferències coherents i acumulatives.
4. **Control multi-escala y seguridad**  
   - PID TSR evita que la flota perdi eficàcia aerodinàmica; la política optimitza paràmetres buscant \(\Delta P\) positiu mentre la penalització de càrregues evita solucions perilloses.

### Propuestas de mejora priorizadas (qué implementar y por qué)
**Alta prioridad (impacte alt, implementació moderada)**
- **Filtrado robust per la mesura \(J\)**: mitjana mòbil + winsorització abans d’usar \(J\) en la política. Redueix soroll i evita actualitzacions erràtiques.  
- **Repeteix pertorbacions** en gradient finit (3 repeticions) i usar la mitjana de \(J_+\) i \(J_-\) per estimar gradient. Millora la convergència.  
- **Limitador de pas** per a cada component de \(x\) (p.ex. màx 5% relatiu per actualització) per evitar salts bruscos.
**Mitja prioritat (impacte mitjà, implementació moderada)**
- **Surrogate model per política**: recollir \((x,J)\) i entrenar un surrogate (RF o MLP petit). Usar-lo per fer cerca global i refinar la política abans d’aplicar canvis reals.  
- **K_ind amb integrador per clúster**: acumular dèficit i actualitzar \(K_{ind}\) amb integrador suau per evitar oscil·lacions per reaccions instantànies.  
- **FFT windowing i normalització** per fer la detecció de mode més robusta a ráfegues.

El que diu la física fonamental:

La gravetat és una força conservativa. En un cicle tancat ∮F·dr = 0 sempre. No hi ha manera de treure energia neta d'un rotor que torna al mateix punt. Açò no és una limitació del model — és termodinàmica.

Però hi ha un matís important que el model actual NO explota correctament:

El ratchet Fe+oli que tens al Quijote NO és un cicle tancat si la massa es desplaça físicament amb un actuador. Si gastes energia elèctrica (o pneumàtica) per moure la massa radialment, llavors:

W_net = W_vent_captat_extra - W_actuador_massa
Si W_vent_extra > W_actuador, tens guany real. Açò és exactament el principi del pitch actiu en aerogeneradors moderns — i funciona.

El que el model v3.1/v4 fa malament:

La massa es mou "sola" per conservació d'energia — el model no comptabilitza el cost de moure-la. Per tant el balanç és sempre zero o negatiu. No és física nova, és comptabilitat incompleta.

def build_wind(cfg):
    np.random.seed(cfg.SEED)
    steps = cfg.STEPS
    ou = np.zeros(steps)
    for i in range(1, steps):
        ou[i] = ou[i-1] - 0.5*ou[i-1]*cfg.DT + 0.8*np.sqrt(cfg.DT)*np.random.randn()
    v_arr = np.zeros(steps)
    for s in range(steps):
        t = s * cfg.DT
        v = cfg.V_BASE + 2*np.sin(2*np.pi*t/20) + ou[s]*0.6
        if 40 < t < 60:
            v -= 5*np.sin(np.pi*(t-40)/20)
        v_arr[s] = max(3.0, v)
    return v_arr


def eta_cp(cfg, omega, v):
    if v <= 0: return 0.0
    lam = omega * cfg.R / v
    return float(max(0, 1 - ((lam - cfg.LAM_OPT)/cfg.LAM_OPT)**2))

            v = out[f'Jvar_sin_N{N}']
            print(f"  N={N} sinusoidal: J_var={v:.5f}%  "
                  f"{'✓ CONSTANT (Ec.7)' if v<0.01 else '✗'}")
        print(f"  W_hurto/volta/pala (Ec.4) = {out['W_volta_pala_kJ']:.2f} kJ")
    return out

# NUCLI DE SIMULACIÓ
# ═══════════════════════════════════════════════════════════════════════════════

def radial_target(cfg, mode, th, omega, r_now):
    """Retorna (r_target, F_extra) segons el mode de control."""
    cos_th = np.cos(th)
    if mode == 'paper':
        return (cfg.R_TIP if cos_th > 0 else cfg.R_HUB), 0.0
    if mode == 'sinusoidal':
        return cfg.r0 + cfg.A_amp*cos_th, 0.0
    # control: compensació centrífuga
    F_c = cfg.m_q * omega**2 * r_now
    r_opt0 = cfg.R_TIP - (cfg.R_TIP-cfg.R_HUB)*(1+cos_th)/2
    r_opt  = r_opt0 + cfg.K_COMP*(F_c/(cfg.K_Q*(cfg.R_TIP-cfg.R_HUB)+1e-9))
    return float(np.clip(r_opt, cfg.R_HUB, cfg.R_TIP)), 0.0


def simulate(cfg, N_pales, mode, v_arr):
    """Simula N_pales en mode donat. Retorna dict de resultats."""
    m_q   = cfg.m_q
    steps = cfg.STEPS
    DT    = cfg.DT

    thetas = np.array([2*np.pi*k/N_pales for k in range(N_pales)])
    omega  = cfg.OM_RATED * 0.95
    r_q    = np.full(N_pales, cfg.r0)
    dr_q   = np.zeros(N_pales)

    # Buffer hidràulic
    V_BUF_MAX=0.10; Q_BOMBA=0.010; P_ACC_MAX=20e6
    LLINDAR=20.0; ETA_GEN=0.85; V_buf=0.0; P_acc=0.0

    # Historials
    H = {k: np.zeros(steps) for k in
         ['Pa','Pg','om','J_tot','P_hurto','P_act','P_net','P_inert']}

    E = dict(vent=0., xarxa=0., frec=0., gen=0.,
             act_pos=0., act_neg=0., hurto=0.)
    J_prev = sum(m_q * r**2 for r in r_q)

    for s in range(steps):
        v = v_arr[s]
        om_target = min(cfg.OM_RATED, cfg.LAM_OPT*max(v,0.1)/cfg.R)
        omega += (om_target - omega)*(DT/3.0)
        omega  = float(np.clip(omega, cfg.OM_RATED*0.3, cfg.OM_RATED*1.4))

        Pa = 0.5*cfg.RHO_A*cfg.A_ROT*cfg.CP_MAX*eta_cp(cfg,omega,v)*v**3

        dJ_total=0.; T_hurto_s=0.; P_act_s=0.; J_tot_s=0.

        for i in range(N_pales):
            th = thetas[i] % (2*np.pi)
            cos_th = np.cos(th)

            r_target, _ = radial_target(cfg, mode, th, omega, r_q[i])
            F_c_i    = m_q * omega**2 * r_q[i]
            F_ctrl   = -cfg.K_Q * (r_q[i] - r_target)
            F_fric_r = -cfg.C_FRIC * dr_q[i]
            acc      = (F_c_i + F_ctrl + F_fric_r) / m_q

            dr_q[i] += acc*DT
            dr_q[i]  = float(np.clip(dr_q[i], -cfg.DR_MAX, cfg.DR_MAX))
            lim_pos  = omega * r_q[i]
            dr_q[i]  = float(np.clip(dr_q[i], -lim_pos, lim_pos))
            r_q[i]   = float(np.clip(r_q[i] + dr_q[i]*DT, cfg.R_HUB, cfg.R_TIP))

            # Par hurto (Ec.4): τ = m·g·r·cos(θ)
            T_hurto_i = m_q * cfg.G * r_q[i] * cos_th

            # Auditoria actuador: F_cent + F_grav_rad
            F_cent_i   = m_q * omega**2 * r_q[i]
            F_grav_rad = m_q * cfg.G * cos_th
            P_act_i    = (F_cent_i + F_grav_rad) * dr_q[i]

            T_hurto_s += T_hurto_i
            P_act_s   += P_act_i
            if P_act_i > 0: E['act_pos'] += P_act_i*DT
            else:           E['act_neg'] += abs(P_act_i)*DT

            dJ_total += 2*m_q*r_q[i]*dr_q[i]
            E['frec'] += (-cfg.C_FRIC*dr_q[i]**2)*DT
            J_tot_s   += m_q * r_q[i]**2

        P_hurto_s = T_hurto_s * omega
        P_net_s   = P_hurto_s - P_act_s
        P_inert_s = (J_tot_s - J_prev)/DT * omega
        J_prev    = J_tot_s
        E['hurto'] += P_hurto_s*DT

        H['P_hurto'][s]=P_hurto_s; H['P_act'][s]=P_act_s
        H['P_net'][s]=P_net_s; H['P_inert'][s]=P_inert_s; H['J_tot'][s]=J_tot_s

        # Kuramoto
        for i in range(N_pales):
            kc  = (cfg.K_KUR/N_pales)*float(np.sum(np.sin(thetas - thetas[i])))
            dJi = 2*m_q*r_q[i]*dr_q[i]
            pm  = float(np.clip(2.0*np.cos(thetas[i]) + 0.5*omega*np.sin(thetas[i])
                                - 0.6*dJi, -8, 8))
            thetas[i] += (omega + kc + pm*0.01)*DT

        # Buffer hidràulic
        P_buf = -omega * dJ_total
        Pgen  = 0.0
        if P_buf > LLINDAR and V_buf < V_BUF_MAX:
            P_acc = min(P_acc + P_buf*DT/V_BUF_MAX, P_ACC_MAX)
            Q     = min(Q_BOMBA, P_buf/max(P_acc, 1e3))
            V_buf = min(V_BUF_MAX, V_buf + Q*DT)
        elif P_buf < -LLINDAR and V_buf > 0:
            P_acc = max(P_acc + P_buf*DT/V_BUF_MAX, 0)
            Q     = min(Q_BOMBA, -P_buf/max(P_acc, 1e3))
            Pgen  = P_acc*Q*ETA_GEN
            V_buf = max(0, V_buf - Q*DT)

        Pg = max(0, Pa*(1+0.04) + max(0,P_buf) + Pgen)
        E['vent']+=Pa*DT; E['xarxa']+=Pg*DT; E['gen']+=Pgen*DT
        H['Pa'][s]=Pa; H['Pg'][s]=Pg; H['om'][s]=omega

    E_net_act = (E['act_pos'] - E['act_neg']) / 3.6e6
    E_hurto_kwh = E['hurto'] / 3.6e6

    return {
        'N': N_pales, 'mode': mode, 'H': H,
        'P_hurto_mean': float(np.mean(np.abs(H['P_hurto']))/1e3),
        'P_act_mean':   float(np.mean(np.abs(H['P_act']))/1e3),
        'P_net_mean':   float(np.mean(H['P_net'])/1e3),
        'P_inert_mean': float(np.mean(H['P_inert'])/1e3),
        'E_hurto':      E_hurto_kwh,
        'E_act_pos':    E['act_pos']/3.6e6,
        'E_act_neg':    E['act_neg']/3.6e6,
        'E_net_act':    E_net_act,
        'eff_hurto':    E_hurto_kwh/(E_net_act+1e-9),
        'E_vent':       E['vent']/3.6e6,
        'E_xarxa':      E['xarxa']/3.6e6,
        'millora':      float((np.mean(H['Pg'])-np.mean(H['Pa']))/np.mean(H['Pa'])*100),
        'J_var':        float(100*(H['J_tot'].max()-H['J_tot'].min())/(H['J_tot'].mean()+1e-9)),
        'W_analitic_kJ':float(m_q*cfg.G*cfg.delta_r*4*N_pales/1e3),
    }

def export_csv(results, path):
    keys = ['N','mode','P_hurto_mean','P_act_mean','P_net_mean','P_inert_mean',
            'E_hurto','E_act_pos','E_act_neg','E_net_act','eff_hurto',
            'E_vent','E_xarxa','millora','J_var','W_analitic_kJ']
    with open(path, 'w', newline='') as f:
        w = csv.DictWriter(f, fieldnames=keys)
        w.writeheader()
        for r in results:
            w.writerow({k: r.get(k) for k in keys})
    print(f"  CSV: {path}")

def main():
    ap = argparse.ArgumentParser(description="Quijote hurto gravitatori — regles paper")
    ap.add_argument('--mode', choices=['paper','sinusoidal','control','all'],
                    default='all', help="Mode de control (default: all)")
    ap.add_argument('--N', type=int, choices=[3,7,0], default=0,
                    help="Nombre d'aspes (0=ambdós, default)")
    ap.add_argument('--no-plots', action='store_true', help="No generar gràfics")
    ap.add_argument('--no-exports', action='store_true', help="No generar CSV/LaTeX")
    ap.add_argument('--out', default='/mnt/user-data/outputs', help="Directori de sortida")
    ap.add_argument('--T', type=float, default=90.0, help="Durada simulació [s]")
    args = ap.parse_args()

    os.makedirs(args.out, exist_ok=True)
    cfg = Config()
    cfg.T_TOT = args.T

    modes = ['paper','sinusoidal','control'] if args.mode=='all' else [args.mode]
    Ns    = [3,7] if args.N==0 else [args.N]

    print("═"*72)
    print("  QUIJOTE — Hurto Gravitatori (regles paper Ec.2)  v3")
    print("  Víctor Manzanares Alberola — EPSA UPV Alcoi")
    print("═"*72)
    print(f"  T={cfg.T_TOT:.0f}s  DT={cfg.DT}s  modes={modes}  N={Ns}")
    print(f"  m_q={cfg.m_q:.1f} kg/pala  Δr={cfg.delta_r:.0f}m  "
          f"ω_rated={cfg.OM_RATED:.3f} rad/s\n")

    print("── Verificació analítica ──")
    analytics = verify_analytics(cfg)

    print("\n── Simulació ──")
    v_arr = build_wind(cfg)
    results = []
    for N in Ns:
        for mode in modes:
            print(f"  N={N} mode={mode}...", end='', flush=True)
            r = simulate(cfg, N, mode, v_arr)
            results.append(r)
            mark = '✓' if r['P_net_mean']>0 else '✗'
            print(f" P_net={r['P_net_mean']:+.2f}kW eff={r['eff_hurto']:.2f}× {mark}")

    # Resum
    print("\n" + "═"*72)
    print(f"  {'Config':<18}{'P_hurto':>9}{'P_act':>8}{'P_net':>9}"
          f"{'Eff':>7}{'Patin':>8}{'Millora':>9}{'J_var':>8}")
    print("  " + "-"*74)
    for r in results:
        mk='✓' if r['P_net_mean']>0 else '✗'
        print(f"  {r['N']}p {r['mode']:<13}{r['P_hurto_mean']:>9.1f}"
              f"{r['P_act_mean']:>8.1f}{r['P_net_mean']:>9.2f}"
              f"{r['eff_hurto']:>7.2f}{r['P_inert_mean']:>8.1f}"
              f"{r['millora']:>8.2f}%{r['J_var']:>7.1f}% {mk}")

    if len(Ns)==2 and 'paper' in modes:
