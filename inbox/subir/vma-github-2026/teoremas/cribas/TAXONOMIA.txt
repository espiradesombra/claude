CINCO FAMILIAS (qué hace cada una)
--------------------------------------------------------------------------------

  ID   | Nombre              | Objetivo                    | Salida
  -----|---------------------|-----------------------------|------------------------
  C1   | Criva racional      | Estimar π(x)/x              | Densidad Dₙ, no lista de primos
  C2   | Criba desmemoriada  | Generar primos distribuido  | Lista booleana B
  C3   | Criba modular 6k±1  | Generar primos en rejilla   | Array p[v], marcado único
  C4   | Criba híbrida       | Optimizar C3 (fallo/remarca)| Misma que C3, menos remarcas
  C5   | Sofí (estructural)  | Clasificar L₁ en L₃/L₄/U₂   | Conjuntos, no algoritmo de Eratóstenes
  C6   | SunRaman–Eratóstenes| Compuestos diofánticos 6k±1 | Mapa v / bloques 1MB Gvma

--------------------------------------------------------------------------------
C1 — CRIVA (densidad, no criba clásica)
--------------------------------------------------------------------------------
  Iteración: Dₙ₊₁ = Dₙ + s·(T − Dₙ)  con T = π(x)/x objetivo
  Equivalente punto fijo: Dₙ₊₁ = (Dₙ + T)/2  (s = ½)
  Capas: producto de Euler Π(1−1/p) como D₀
  Error: eₙ = e₀·|1−s|ⁿ  →  n ≥ log₂(e₀/ε)
  Archivo: CRIVA_RACIONAL.txt | Código: repo\py\criva.py

--------------------------------------------------------------------------------
C2 — CRIBA DESMEMORIADA
--------------------------------------------------------------------------------
  Patrón base 6k±1 en listas booleanas (1=quizás primo, 0=compuesto)
  Replicación + AND entre nodos → memoria distribuida
  Pseudocódigo §8.1 del tratado
  Archivo: CRIBA_DESMEMORIADA.txt | Código: repo\py\cribas.py

--------------------------------------------------------------------------------
C3 — CRIBA MODULAR 6k±1
--------------------------------------------------------------------------------
  Candidatos: value(i) = 2i+3  (solo clases 6k±1, impares > 3)
  Marca compuestos (2n+3)(2m+3) con saltos +2p y +4p
  anteriorM: evita índices múltiplos de 3 inválidos
  anteriorNY: marcado único (menor factor en rejilla)
  Complejidad práctica: Θ(l²) con marcado único
  Archivo: CRIBA_MODULAR_6kpm1.txt | archivos\criba_modular.py

--------------------------------------------------------------------------------
C4 — CRIBA HÍBRIDA
--------------------------------------------------------------------------------
  Fase 1: criba ascendente hasta ~límite/2
  Fase 2: descendente con semilla de residuos
  Paralelo: anexoF_criba6kpm1_openmp.c
  Archivo: CRIBA_HIBRIDA.txt | archivos\criba_hibrida.py

--------------------------------------------------------------------------------
C5 — SOFÍ (criba conceptual sobre L₁)
--------------------------------------------------------------------------------
  L₁ = { n ≡ 5 (mod 6) }  ≡  { 6k−1 }
  L₃: n compuesto por forma (6k−1)(6h+1)
  L₄: 2n+1 compuesto por forma (6j−1)(6g+1)
  L₂ = L₃ ∩ L₄  |  U₂ = L₁ \ (L₃ ∪ L₄)  |  Lsg = supervivientes
  PIE: |Lsg| = |L₁| + |L₂| − |L₃| − |L₄|
  No elimina números uno a uno: clasifica por plantilla modular
  Archivo: SOFI_ESTRUCTURA_PIE.txt | formal\F04–F05, F28

--------------------------------------------------------------------------------
C6 — SUNRAMAN JET (SUNDARAM + RUEDA 6k±1 + SEGMENTOS)
--------------------------------------------------------------------------------
  Ecuación: v = 2nm + 3n + 3m + 3  ↔  (2n+3)(2m+3) = 2v+3
  No requiere lista de primos (como Sundaram); persistencia segmentada (como Eratóstenes moderno)
  Librería Gvma.h: bloques 1MB, bit-packing, factorizador Flash (pinza)
  Maniobra Jet: salto de m cuando f1 > √N
  Archivo: CRIBA_SUNRAMAN_ERATOSTENES.txt

¿CUÁL USAR?
--------------------------------------------------------------------------------
  ¿Lista de primos hasta N?        → C3 o C4
  ¿HPC / nodos distribuidos?       → C2 o C6 (bloques 1MB incrementales)
  ¿GPU / sin if(primo)?             → C6 SunRaman Jet
  ¿Densidad local π(x)/x?          → C1
  ¿Demostrar no colapso estructural? → C5 + PIE (F28)
  ¿Goldbach / parejas?             → C5 + metodos\ (no C1 solo)
