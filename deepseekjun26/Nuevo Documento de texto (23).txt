def and_classic(v1, f1, v2, f2):
    # Ignora fases, les posa a 0
    return (v1, 0, v1 & v2, 0)

def toffoli_quantum(v1, f1, v2, f2):
    # Preserva f1, ignora f2
    return (v1, f1, v1 & v2, 0)

def toffoli_classic_with_phase(v1, f1, v2, f2):
    # Versió clàssica que també preserva f1 però sense "coherència"
    # Això és perfectament implementable amb bits normals
    return (v1, f1, v1 & v2, 0)  # idèntic al quàntic!

def shift_state(v1, v2, f1, f2):
    # Permuta només els bits de valor segons: 00->11, 01->10, 11->00, 10->01
    state = (v1, v2)
    shift_map = {(0,0): (1,1), (0,1): (1,0), (1,1): (0,0), (1,0): (0,1)}
    v1_new, v2_new = shift_map[state]
    return (v1_new, v2_new, f1, f2)

def feedback_loop(initial, gate_func, cycles=6):
    S = initial
    trajectory = [S]
    for _ in range(cycles):
        # A = AND clàssic sobre S sense desfasar
        A = and_classic(*S)
        # T = gate_func sobre S desfasar
        S_shifted = shift_state(*S)
        T = gate_func(*S_shifted)
        D = tuple(a ^ t for a, t in zip(A, T))
        S_next = tuple(s | d for s, d in zip(S, D))
        trajectory.append(S_next)
        S = S_next
    return trajectory

def hamming_distance(trajA, trajB):
    return [sum(1 for a,b in zip(sA, sB) if a != b) for sA, sB in zip(trajA, trajB)]

# Estats inicials
S_A = (0, 0, 1, 0)  # v1=0, f1=0, v2=1, f2=0
S_B = (0, 1, 1, 0)  # f1=1

# Prova amb Toffoli quàntic
trajA_q = feedback_loop(S_A, toffoli_quantum)
trajB_q = feedback_loop(S_B, toffoli_quantum)
dist_q = hamming_distance(trajA_q, trajB_q)
print("Toffoli quàntic (preserva fase):", dist_q)

# Prova amb Toffoli clàssic amb fase (idèntic!)

# Prova amb AND clàssic (destrueix fase)
trajA_and = feedback_loop(S_A, and_classic)

def shift(state):
    v1, f1, v2, f2 = state
    m = {(0,0):(1,1), (0,1):(1,0), (1,1):(0,0), (1,0):(0,1)}
    v1n, v2n = m[(v1, v2)]
    return (v1n, v2n, f1, f2)

def toffoli(state):
    v1, f1, v2, f2 = state
    return (v1, f1, v1 & v2, 0)

def xor_sum(states):
    # states és llista de tuples de 4 bits
    result = [0,0,0,0]
    for s in states:
        for i in range(4):
            result[i] ^= s[i]
    return tuple(result)

def feedback_loop(initial, cycles=6):
    S = initial
    traj = [S]
    for _ in range(cycles):
        S0 = toffoli(S)               # camí sense desfasar
        S1 = toffoli(shift(S))        # camí desfasat
        T_total = xor_sum([S0, S1])
        S_next = tuple(S[i] | T_total[i] for i in range(4))
        traj.append(S_next)
        S = S_next
    return traj

S_A = (0,0,1,0)
S_B = (0,1,1,0)

trajB = feedback_loop(S_B)

METHOD: Phase‑Boolean Feedback with K‑Path Summation
Technical exploration of K‑shifted Toffoli sums for phase‑sensitive logic
Versió: 1.0
Autor: 1477 / 33x1

1. State encoding (4 bits)
A two‑qubit system with Boolean phase encoding:

v1 : value of qubit 1 (0 or 1)

f1 : phase of qubit 1 (0 → +1, 1 → –1)

v2 : value of qubit 2

f2 : phase of qubit 2

State: S = (v1, f1, v2, f2) ∈ {0,1}⁴.

2. Permutation (phase shift)
Only the value bits (v1, v2) are permuted following a cyclic Gray order:

(v1, v2)	shift(v1, v2)
00	11
01	10
11	00
10	01
The phase bits (f1, f2) remain in the same position (they are not permuted, only the values move).

Formally:
shift(v1, f1, v2, f2) = (v1', v2', f1, f2)
where (v1', v2') is given by the table above.

3. Quantum Boolean gate (Toffoli)
Toffoli gate that preserves the phase of the first qubit and sets the second qubit’s phase to 0:

Toffoli(S) = (v1, f1, v1∧v2, 0)

The same structure can be used for other gates (CNOT, CZ, etc.) by changing the Boolean operation on values.

4. K‑path sum
For a given integer K ≥ 1, define the sum (XOR) of the Toffoli outputs applied to K successive shifts of S:

T_K(S) = Toffoli(S) ⊕ Toffoli(shift(S)) ⊕ Toffoli(shift²(S)) ⊕ … ⊕ Toffoli(shift^{K-1}(S))

where ⊕ is bitwise XOR.

5. Feedback rule
Two possible feedback rules:

OR feedback:
S_next = S OR T_K(S) (bitwise OR)

XOR feedback:
S_next = S XOR T_K(S) (bitwise XOR)

The process is iterated for a fixed number of cycles (e.g., 6).

6. Invariants
For XOR feedback, the following holds:

Because every Toffoli output has f2 = 0, the XOR of any number of them also has f2 = 0.

Then f2_next = f2 ⊕ 0 = f2.

Invariant: f2 never changes. The state space splits into two disconnected subsets: f2=0 and f2=1.

For OR feedback, no simple bitwise invariant exists (but global attractors may appear).

7. Initial conditions for phase sensitivity test
We compare two trajectories starting from states that are identical except for f1:

S_A = (0, 0, 1, 0) (f1 = 0)

S_B = (0, 1, 1, 0) (f1 = 1)

Both have f2 = 0 (same subset).

We compute the Hamming distance between the two trajectories at each cycle:

D(t) = Hamming( S_A(t), S_B(t) ) where S_A(0) = S_A, S_B(0) = S_B.

8. Exploration plan (K and feedback)
We systematically vary:

K = 1, 2, 3, 4, 5, 6, 7, 8 (since shift⁴ = identity, K > 4 may repeat patterns with different parity)

Feedback = OR, XOR

For each combination, compute:

The full transition function for all 16 states.

The cycles (period, number of cycles, fixed points).

The distance evolution D(t) for the two initial states S_A, S_B.

Whether the difference in f1 ever propagates to the value bits v1 or v2 in a persistent way (i.e., after some cycle, all future states have v1 or v2 different between the two trajectories).
