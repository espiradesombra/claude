¿Qué es el ciclo Belt?
En computación y autómatas, el cycle belt es una estructura donde los datos están organizados en una cinta (“belt”) que avanza ciclo a ciclo. Hay registros o nodos que reciben, procesan y pasan información en paralelo o turnos (como pipeline o conveyor).
Se usa, por ejemplo, en arquitecturas de CPUs “belt machine”, autómatas celulares reversibles, máquinas de Turing de múltiples cabezas, etc.

3. Tablas y Formalismos de Mecánica Cuántica
En cuántica real:

Estados: Se describen por vectores (|0⟩, |1⟩, |ψ⟩ = α|0⟩ + β|1⟩) y matrices densidad, no con bits, sino con amplitudes complejas (números reales o complejos).
Diferencia clave: La “fase” es un ángulo (cambia el resultado de interferencias), y no se reduce a un bit 0/1.
Evolución: Se describe por matrices unitarias (U), tablas de tiros para puertas cuánticas como X, Z, H, CNOT, Toffoli, etc.
Las tablas de transición: En cuántica, una tabla no es solo de ceros y unos: muestra para cada estado base cómo se mezclan/superponen y cómo cambia la fase (ejemplo: la puerta Z invierte la fase de |1⟩).
Aspecto	Método 1477 (Booleano)	Tablas Cuánticas reales
Representación	Bit de valor y bit de fase	Amplitud compleja y ángulo
Evolución	Reglas XOR/OR, feedback	Operadores unitarios, interferencia
Diferencia de fase	Bit binario (0/1 = +1/-1)	Ángulo cualquier (θ en [0,2π]), superposición continua
Amplificación	“Fase escondida” se vuelve bit observable bajo ciertas dinámicas	Interferencia produce máximos/mínimos, posibilidad de amplificación por caminos cuánticos
Reversibilidad	Sí para XOR, en general no	Siempre reversible (unitarios)
Conclusión comparativa:

El método 1477 emula sólo un subconjunto muy concreto y simplificado de la dinámica cuántica.
No replica los efectos espectaculares de interferencia, superposición, ni viola las desigualdades de Bell, pero es un excelente punto de partida educativo para entender cómo reglas simples pueden amplificar diferencias y cómo la complejidad de la mecánica cuántica aparece cuando la “fase” deja de ser binaria.
En una tabla cuántica, aunque empieces con estados idénticos salvo por la fase, los resultados de experimentos (e.g., interferencia tipo Mach–Zehnder, algoritmos de Grover, etc.) sí pueden amplificarse y diferenciarse, pareciéndose superficialmente al fenómeno booleano, pero por mecanismos matemáticos mucho más ricos.

## 4. ¿Qué significa "usar el mismo método de realimentación"?

Si intentáramos **diseñar un feedback cuántico análogo al booleano** (suma de Toffolis, desplazamientos, etc.), el resultado sería muy diferente porque:
- En cuántica, "sumar" es lineal (amplitudes), no XOR.
- Las puertas como Toffoli son unitarias y reversibles.
- La realimentación implicaría aplicar una secuencia de puertas y luego repetirla, generando **interferencia** entre caminos.

En la práctica, ese feedback cuántico produciría que **dos estados que solo difieren en una fase global** se comporten igual (la fase global no es observable), pero si la fase está en un qubit relativo, entonces sí puede amplificarse mediante puertas como Hadamard + controladas, produciendo resultados de medición muy distintos.

import numpy as np
import matplotlib.pyplot as plt

# ------------------------------------------------------------
# 4 qubits: |v1, f1, v2, f2> -> índice = v1*8 + f1*4 + v2*2 + f2
# ------------------------------------------------------------

def index(v1, f1, v2, f2):
    return (v1 << 3) | (f1 << 2) | (v2 << 1) | f2

def basis_state(v1, f1, v2, f2):
    vec = np.zeros(16, dtype=complex)
    vec[index(v1, f1, v2, f2)] = 1.0
    return vec

def gray_shift(v1, v2):
    """Gray code shift as in 1477 method"""
    mapping = {(0,0):(1,1), (0,1):(1,0), (1,1):(0,0), (1,0):(0,1)}
    return mapping[(v1, v2)]

def apply_gray_shift_to_state(psi):
    """Permute amplitudes according to Gray shift on (v1, v2)"""
    new_psi = np.zeros(16, dtype=complex)
    for v1 in (0,1):
        for f1 in (0,1):
            for v2 in (0,1):
                for f2 in (0,1):
                    v1p, v2p = gray_shift(v1, v2)
                    old_idx = index(v1, f1, v2, f2)
                    new_idx = index(v1p, f1, v2p, f2)
                    new_psi[new_idx] += psi[old_idx]
    return new_psi

def apply_toffoli(psi):
    """Classical Toffoli: (v1, f1, v2, f2) -> (v1, f1, v1&v2, 0)"""
    new_psi = np.zeros(16, dtype=complex)
    for v1 in (0,1):
        for f1 in (0,1):
            for v2 in (0,1):
                for f2 in (0,1):
                    v1_out = v1
                    f1_out = f1
                    v2_out = v1 & v2
                    f2_out = 0
                    out_idx = index(v1_out, f1_out, v2_out, f2_out)
                    in_idx = index(v1, f1, v2, f2)
                    new_psi[out_idx] += psi[in_idx]
    return new_psi

def feedback_1477_quantum(psi, K=3):
    """Quantum coherent feedback: sum over K shifted paths, each Toffoli'd."""
    paths = [psi]
    current = psi
    for _ in range(K-1):
        current = apply_gray_shift_to_state(current)
        paths.append(current)
    total = np.zeros(16, dtype=complex)
    for p in paths:
        total += apply_toffoli(p)
    return total

def normalize(psi):
    norm = np.linalg.norm(psi)
    if norm == 0:
        return psi
    return psi / norm

def measure_prob(psi):
    return np.abs(psi)**2

# ------------------------------------------------------------
# Estados iniciales: solo difieren en f1 (segundo bit)
# Estado A: (0,0,1,0) -> |0,0,1,0>  índice 2
# Estado B: (0,1,1,0) -> |0,1,1,0>  índice 6
# ------------------------------------------------------------
psiA = basis_state(0,0,1,0)   # |0,0,1,0>
psiB = basis_state(0,1,1,0)   # |0,1,1,0>   # diferencia en f1

K = 3
cycles = 8
history_a = [psiA.copy()]
history_b = [psiB.copy()]
pa, pb = psiA.copy(), psiB.copy()

for _ in range(cycles):
    pa = feedback_1477_quantum(pa, K)
    pb = feedback_1477_quantum(pb, K)
    pa = normalize(pa)
    pb = normalize(pb)
    history_a.append(pa.copy())
    history_b.append(pb.copy())

# ------------------------------------------------------------
# Visualización

def plot_4qubit_evolution(history_a, history_b):
    steps = range(len(history_a))
    labels = [f'|{v1}{f1}{v2}{f2}⟩' for v1 in (0,1) for f1 in (0,1) for v2 in (0,1) for f2 in (0,1)]
    fig, axes = plt.subplots(1, 2, figsize=(16,5))
    for i, (hist, title) in enumerate([(history_a, 'A: |0,0,1,0⟩'), (history_b, 'B: |0,1,1,0⟩')]):
        probs = np.array([measure_prob(state) for state in hist])
        for j in range(16):
            axes[i].plot(steps, probs[:,j], label=labels[j])
        axes[i].set_title(title)
        axes[i].set_xlabel('Ciclo')
        axes[i].set_ylabel('Probabilidad')
        axes[i].set_ylim(0,1)
        axes[i].legend(ncol=2, fontsize=6)
        axes[i].grid(True)
    plt.tight_layout()
    plt.show()

def boolean_toffoli(v1, f1, v2, f2):
    return (v1, f1, v1 & v2, 0)

def boolean_gray_shift(v1, v2):
    mapping = {(0,0):(1,1), (0,1):(1,0), (1,1):(0,0), (1,0):(0,1)}
    return mapping[(v1, v2)]

def boolean_sum_toffoli(state, K=3):
    v1, f1, v2, f2 = state
    states = [state]
    for _ in range(K-1):
        v1, v2 = boolean_gray_shift(v1, v2)
        states.append((v1, f1, v2, f2))
    total = [0,0,0,0]
    for s in states:
        t = boolean_toffoli(*s)
        total = [total[i] ^ t[i] for i in range(4)]
    return tuple(total)

def boolean_feedback_step(state, K=3):
    return tuple([state[i] ^ boolean_sum_toffoli(state, K)[i] for i in range(4)])

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import Normalize
import csv

# ------------------------------------------------------------
# 4 qubits: |v1, f1, v2, f2> -> índice = v1*8 + f1*4 + v2*2 + f2
# ------------------------------------------------------------
def index(v1, f1, v2, f2):
    return (v1 << 3) | (f1 << 2) | (v2 << 1) | f2

def basis_state(v1, f1, v2, f2):
    vec = np.zeros(16, dtype=complex)
    vec[index(v1, f1, v2, f2)] = 1.0
    return vec

def gray_shift(v1, v2):
    mapping = {(0,0):(1,1), (0,1):(1,0), (1,1):(0,0), (1,0):(0,1)}
    return mapping[(v1, v2)]

def apply_gray_shift_to_state(psi):
    new_psi = np.zeros(16, dtype=complex)
    for v1 in (0,1):
        for f1 in (0,1):
            for v2 in (0,1):
                for f2 in (0,1):
                    v1p, v2p = gray_shift(v1, v2)
                    old_idx = index(v1, f1, v2, f2)
                    new_idx = index(v1p, f1, v2p, f2)
                    new_psi[new_idx] += psi[old_idx]
    return new_psi

def apply_toffoli(psi):
    new_psi = np.zeros(16, dtype=complex)
    for v1 in (0,1):
        for f1 in (0,1):
            for v2 in (0,1):
                for f2 in (0,1):
                    v1_out = v1
                    f1_out = f1
                    v2_out = v1 & v2
                    f2_out = 0
                    out_idx = index(v1_out, f1_out, v2_out, f2_out)
                    in_idx = index(v1, f1, v2, f2)
                    new_psi[out_idx] += psi[in_idx]
    return new_psi

def feedback_1477_quantum(psi, K=3):
    paths = [psi]
    current = psi
    for _ in range(K-1):
        current = apply_gray_shift_to_state(current)
        paths.append(current)
    total = np.zeros(16, dtype=complex)
    for p in paths:
        total += apply_toffoli(p)
    return total

def normalize(psi):
    norm = np.linalg.norm(psi)
    if norm == 0:
        return psi
    return psi / norm

def measure_prob(psi):
    return np.abs(psi)**2

def fidelity(psi1, psi2):
    """Fidelidad cuántica |<ψ1|ψ2>|²"""
    return np.abs(np.vdot(psi1, psi2))**2

# ------------------------------------------------------------
# Estados iniciales: solo difieren en f1
# A: |0,0,1,0>   B: |0,1,1,0>
# ------------------------------------------------------------
psiA = basis_state(0,0,1,0)
psiB = basis_state(0,1,1,0)

K = 3
cycles = 8
history_a = [psiA.copy()]
history_b = [psiB.copy()]
fidelity_history = [fidelity(psiA, psiB)]
pa, pb = psiA.copy(), psiB.copy()

for _ in range(cycles):
    pa = feedback_1477_quantum(pa, K)
    pb = feedback_1477_quantum(pb, K)
    pa = normalize(pa)
    pb = normalize(pb)
    history_a.append(pa.copy())
    history_b.append(pb.copy())
    fidelity_history.append(fidelity(pa, pb))

# Gráfica de evolución de probabilidades (16 bases)
# ------------------------------------------------------------
def plot_4qubit_evolution(history_a, history_b):
    steps = range(len(history_a))
    labels = [f'|{v1}{f1}{v2}{f2}⟩' for v1 in (0,1) for f1 in (0,1) for v2 in (0,1) for f2 in (0,1)]
    fig, axes = plt.subplots(1, 2, figsize=(16,5))
    for i, (hist, title) in enumerate([(history_a, 'A: |0,0,1,0⟩'), (history_b, 'B: |0,1,1,0⟩')]):
        probs = np.array([measure_prob(state) for state in hist])
        for j in range(16):
            axes[i].plot(steps, probs[:,j], label=labels[j])
        axes[i].set_title(title)
        axes[i].set_xlabel('Ciclo')
        axes[i].set_ylabel('Probabilidad')
        axes[i].set_ylim(0,1)
        axes[i].legend(ncol=2, fontsize=6)
        axes[i].grid(True)
    plt.tight_layout()
    plt.show()

plot_4qubit_evolution(history_a, history_b)

# Visualización de la fase de las amplitudes (último ciclo, o todos)
# ------------------------------------------------------------
def plot_phase_colormap(history, title, cycle=-1):
    """Mapa de colores de la fase (argumento) de las amplitudes en un ciclo dado."""
    if cycle == -1:
        cycle = len(history)-1
    psi = history[cycle]
    phases = np.angle(psi)  # en radianes (-π a π)
    phases_2d = phases.reshape(4,4)  # 4x4 por comodidad visual (v1,f1 vs v2,f2)
    plt.imshow(phases_2d, cmap='hsv', norm=Normalize(vmin=-np.pi, vmax=np.pi))
    plt.colorbar(label='Fase (rad)')
    plt.title(f'{title} - Ciclo {cycle}')
    plt.xlabel('(v2, f2)')
    plt.ylabel('(v1, f1)')
    plt.xticks(ticks=[0,1,2,3], labels=['00','01','10','11'])
    plt.yticks(ticks=[0,1,2,3], labels=['00','01','10','11'])
    plt.show()

# Mostrar fase en el ciclo 0 y en el último ciclo
plot_phase_colormap(history_a, 'Estado A', cycle=0)
plot_phase_colormap(history_a, 'Estado A', cycle=-1)
plot_phase_colormap(history_b, 'Estado B', cycle=0)
plot_phase_colormap(history_b, 'Estado B', cycle=-1)

def export_to_csv(history_a, history_b, fidelity_hist, filename="quantum_1477_data.csv"):
    labels = [f'|{v1}{f1}{v2}{f2}⟩' for v1 in (0,1) for f1 in (0,1) for v2 in (0,1) for f2 in (0,1)]
    with open(filename, 'w', newline='') as csvfile:
        writer = csv.writer(csvfile)
        header = ['Cycle'] + [f'P_A_{l}' for l in labels] + [f'P_B_{l}' for l in labels] + ['Fidelity']
        writer.writerow(header)
        for t in range(len(history_a)):
            probs_a = measure_prob(history_a[t])
            probs_b = measure_prob(history_b[t])
            row = [t] + list(probs_a) + list(probs_b) + [fidelity_hist[t]]
            writer.writerow(row)
    print(f"Datos exportados a {filename}")

export_to_csv(history_a, history_b, fidelity_history)

def boolean_toffoli(v1, f1, v2, f2):
    return (v1, f1, v1 & v2, 0)

def boolean_gray_shift(v1, v2):
    mapping = {(0,0):(1,1), (0,1):(1,0), (1,1):(0,0), (1,0):(0,1)}
    return mapping[(v1, v2)]

def boolean_sum_toffoli(state, K=3):
    v1, f1, v2, f2 = state
    states = [state]
    for _ in range(K-1):
        v1, v2 = boolean_gray_shift(v1, v2)
        states.append((v1, f1, v2, f2))
    total = [0,0,0,0]
    for s in states:
        t = boolean_toffoli(*s)
        total = [total[i] ^ t[i] for i in range(4)]
    return tuple(total)

def boolean_feedback_step(state, K=3):
    return tuple([state[i] ^ boolean_sum_toffoli(state, K)[i] for i in range(4)])

SA = (0,0,1,0)
SB = (0,1,1,0)
statesA = [SA]
statesB = [SB]
for _ in range(cycles):
    SA = boolean_feedback_step(SA, K)
    SB = boolean_feedback_step(SB, K)
    statesA.append(SA)
    statesB.append(SB)

print("\nMétodo booleano (XOR feedback):")
print("Ciclo | Estado A      | Estado B      | Diferencias")
for i in range(cycles+1):
    diff = sum(a != b for a,b in zip(statesA[i], statesB[i]))
    print(f"{i:2d}    | {statesA[i]} | {statesB[i]} | {diff}")

1. Fidelidad cuántica
Se calcula en cada ciclo como |⟨ψ_A|ψ_B⟩|².

Si la fidelidad es 1 → los estados son idénticos (la diferencia de fase se ha perdido).

Si es 0 → son ortogonales (máxima diferencia).

Valores intermedios indican superposición parcial.

Muestro el ciclo 0 (inicial) y el último ciclo para ver cómo ha cambiado la coherencia entre bases.
