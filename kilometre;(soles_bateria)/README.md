# kilometre;(soles_bateria)

**Máquina Kilómetro** (kilo + metro de recorrido): sims, gráficas y notas de batería mecánica / submarina / Stirling.

## Qué es (física)

Ver explicación unificada:

→ **[docs/EXPLICACION_FISICA_ZYPYZAPE_QUIJOTE_KILOMETRO.md](../docs/EXPLICACION_FISICA_ZYPYZAPE_QUIJOTE_KILOMETRO.md)**

Resumen:

- Masa que recorre un trayecto (tubo + sinfín, variantes fluidas/Stirling).
- Control de fricción / flotación / “vuelta y media”.
- Marco sólido: **batería mecánica**, no motor de gravedad perpetuo.
- Se acopla a **ZypyZape** (grupos) y comparte principio de asimetría con **Quijote**.
