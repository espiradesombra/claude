# teoremas — colección formal VMA

Fichas de teoremas, conjeturas y heurísticas VMA (01–30+), más ramas formal / ingeniería / espacial y extractos Apiñon.

**Monorepo:** [espiradesombra/claude](https://github.com/espiradesombra/claude) · ruta: `teoremas/`

## Qué contiene esta carpeta

| Pieza | Contenido |
|-------|-----------|
| `01_…30_*.txt` | Fichas numeradas (dos primos, Sofí, Goldbach, MDC, MRAUV, Fermat, K3…) |
| `formal/` | Formalización F01–F34 y afines |
| `ingenieria/` | Entradas de ingeniería E* |
| `spacial/` | Notas espaciales S* |
| `cribas/, metodos/, segunda_vuelta/` | Anexos de métodos |
| `apinnon_extraido/` | Extractos del monolito Apiñon |
| `porque_no_33x1/, preguntaseria/` | Meta y preguntas |

Empieza por las fichas `01_`…`15_` en la raíz; el resto son profundidad y anexos.
