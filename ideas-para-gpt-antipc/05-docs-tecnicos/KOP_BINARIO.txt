QUE ES
  K3 MicroKernel = Header + blobs KOP + Directory + Footer (K3ND)
  Cada KOP tiene header fijo 16 bytes: id, version, size, flags
  El directorio mapea KOP id -> offset. El runtime salta directo:
    "Necesito Trust" -> offset en directory, sin recorrer todo.

KOP DEFINIDOS (v1)
  001 Identity    DATA      inmutable
  002 DNA         DATA      producer, parents
  003 Signature   DATA      clave KnowledgeBuffer
  004 Trust       DATA      consenso (Axioma 17)
  005 History     DATA      ledger pointer
  006 Compression BEHAVIOR  transforma payload
  007 Encryption  BEHAVIOR
  008 Network     BEHAVIOR  fabric UDP
