QUÉ ES
  Organismo que roba entropía (nanos, pila, basura, ping opcional),
  aplica la máscara Lila, decide con intérprete mutante y ejecuta:
    0 — Criba Desmemoriada (olvido)
    1 — Salto 6k+1
    2 — Salto 6k-1
    3 — Inercia ZypyZape (resonancia MDC)
  Tras cada ciclo borra su rastro en RAM.

EJECUTAR (Windows)
  RUN_ALEATOROVIX.bat
  python aleatorovix.py
  python aleatorovix.py -n 30 --n-mdc 10403
  python demos\demo_organismo.py
  python demos\demo_primos.py
  python demos\demo_mdc_N.py
