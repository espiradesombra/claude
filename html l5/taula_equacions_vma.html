2 · Salto Màxim i conjectura d'Andrica
NomEquació / definicióUtilitat
Conjectura
SaltoMáximo(n)
SaltoMáximo(n) ≈ √n Derivació: k = √n / 3 retorna (2+4) · (k/2) = √n
Cota superior del buit entre primers consecutius; base per Andrica
Interval mínim (dos primers)
I(n) = [n − ⌊√(n+3)⌋ − 3, n + 3] L(n) = ⌊√(n+3)⌋ + 7 K = ⌊⌊√n⌋ · 9/24⌋ m(n) = Σ_{i=2}^{K} (√(n+3) / i!) ≈ (e−2)·√n Criteri: L(n) − m(n) ≥ 2 → ≥2 primers en I(n)
Garanteix l'existència de dos primers en un interval de longitud ~√n
Andrica
Límit asimptòtic
√n − √(n − √n) < 1 lím_{n→∞} (√n − √(n − √n)) → 0 < 1
Coherència de la conjectura d'Andrica per a tot n ≥ 1
3 · Estructura Sofí (tipus Sophie Germain)
NomEquació / definicióUtilitat
Isomorfisme
Conjunts Sofí
L₁ = {n∈ℕ : n ≡ 5 mod 6} L₃ = {a∈L₁ : a = (6k−1)(6h+1)} L₄ = {a∈L₁ : 2a+1 = (6j−1)(6g+1)} L₂ = L₃ ∩ L₄ LSG = {p∈L₁ : p i 2p+1 primers} U₂ = L₁ ∖ (L₃ ∪ L₄) |L₁| + |L₂| − |L₃| − |L₄| = |LSG|
Caracteritza primes de Sophie Germain; U₂ ⊆ LSG i |U₂|=∞ (provat per TXR+Dirichlet)
Infinitud de U₂
Per tot primer q≥5, per TXR existeix r mod 6q tal que p ≡ r mod 6q → p∈L₄∖L₂ Per Dirichlet: infinits tals p → |L₄∖L₂|=∞ Anàlogament |L₃∖L₂|=∞, |L₂|=∞ ∴ |U₂| = ∞
Argument d'infinitud de primes de Sophie Germain via partició modular
Fermat (Férmines)
Fₙ = 2^(2ⁿ) + 1 F₀·F₁·…·Fₙ = Fₙ₊₁ − 2 Bₙ = 2·(F₀·F₁·…·Fₙ) rₙ únic: rₙ≡1 mod 2, rₙ≡2 mod Fₖ (k≤n) → per tot m≥n+1: Fₘ ≡ rₙ mod Bₙ
Alineació modular dels Fermat; criba compacta de files en base 2·∏Fₖ
4 · Conjectura de Goldbach — asimetria i error
NomEquació / definicióUtilitat
Goldbach
Condició de densitat
f(x)·2 ≤ f(2x) (f = π, funció recompte) G(2n) = #{(p,q): p≤q, p+q=2n, ambdós primers}
Si la condició falla → la conjectura seria falsa; el fallo tendeix a 0
Error relatiu (forma 6k)
E(2n) = ((n/6 − 2n/ln(2n)) · 100) / (2n/ln(2n)) G_teo(2n) ≈ 2n / (ln n)² E% = (G(2n)−G_teo(2n)) / G_teo(2n) · 100
Quantifica la desviació; decreix lentament → reforça la conjectura per a tot rang
Asimetria central
A(2n) = (#{q−p>0} − #{q−p<0}) / G(2n) Δ = |q−p| (diferència de cada parell) acumularFALLO += f(i) − (f(2x)−f(2x−i))
Detecta concentració de solucions prop de la meitat; l'alarm mai salta si la distribució decreix
5 · MDC — Mètode Diofàntic Cinemàtic
NomEquació / definicióUtilitat
MDC core
Funció d'ona
D(m) = 2·(2m+3) (candidat divisor) d(m) = frac(N / D(m)) (part decimal) Aritmètica entera exacta: R = N mod D (numerador) D (denominador) Condició de tall: R == D // 2 → D | N
Detecta divisors de N sense aritmètica flotant; base del motor cinemàtic
Velocitat i acceleració
V = ΔR / Δm (diferència primera de R) A = ΔV / Δm (diferència segona) J = ΔA / Δm (jerk, variació d'A) Pinça doble: 4 mesures per direcció Invariant parabòlic: A ≈ const → dent estable
Prediu la posició del mínim sense iterar punt a punt; salt cinemàtic dirigit
Salt Mestre (predicció)
m_next = m − V/A Límit d'iteració: max_iter = 2·⌊log₂(N)⌋ Complexitat reclamada: O(log N)
Salta directament al candidat de tall; redueix iteracions a ordre logarítmic
Acumulador harmònic (radar)
acumulo += acumulo · (1/i) (i = índex de segment) Cerca des de: talla/2 = ⌊√N⌋ // 2 Condició de ressonància: acumulo ≤ llindar_R Si segment no ressona → salt massiu al segment següent
Filtre macroscòpic: criba segments sencers sense entrar en profunditat cinemàtica
Rueda primorial (MDC-U)
p# = 2·3·5·7·…·pₖ (primorial fins pₖ) Densitat activa: φ(p#)/p# Ex. fins p=5: 8/30 ≈ 26.6% de posicions actives Salts de rueda: array de 48 entrades per p#=210
Elimina ≥73% de l'espai abans del radar cinemàtic; combina rueda + pinça doble
